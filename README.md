# Thesis CLI

Open-source CLI for Thesis, an AI value investing research system. Clone the repo, plug in your own Claude Code subscription, run `/analyze TICKER`, and get One Pager, Pitch Deck, and Final Thesis reports as PDF, DOCX, and JSON in `~/thesis/reports/`.

> **Not investment advice.** Thesis is an AI-powered research tool for educational and informational purposes only. Reports are generated by large language models and may contain errors, hallucinations, outdated data, or misinterpretations of financial filings. Nothing produced by Thesis constitutes investment advice. Always conduct independent research and consult a qualified financial advisor before making investment decisions. See full disclaimer at the bottom of this file.

## Quickstart (60 seconds)

```bash
git clone https://github.com/kghoff/thesis-cli.git
cd thesis-cli
npm install
pip install -r requirements.txt
```

### Configure the Thesis Data API

Run:

```bash
npm run setup
```

The setup command writes `~/thesis/config.json`:

```json
{
  "apiBaseUrl": "https://api.thesis-investing.com",
  "apiKey": "thesis_live_...",
  "defaultMode": "hosted-data"
}
```

Thesis CLI is free and open source. The hosted Data API key is free and rate-limited; it is required because local proprietary DataPacket assembly code is not shipped in this repo.

During the private migration, `npm run setup` can write the config file, but real hosted runs require a live API key from thesis-investing.com once key issuing is enabled.

Open Claude Code in this folder, then:

```
/analyze AAPL
```

When the pipeline finishes, open `~/thesis/reports/AAPL/` to see your reports.

## Requirements

- **Node** 20 LTS or newer
- **Python** 3.11 or newer
- **Claude Code subscription** — see [Subscription tier](#subscription-tier) below
- **Free Thesis API key** — create an account at thesis-investing.com and save your API key in `~/thesis/config.json`
- **Disk** ~5 GB for the repo (the bundled earnings transcripts are ~72 MB)

Mac and Linux are tested. Windows works (file issues if not).

## Subscription tier

Thesis runs on your Claude Code subscription — your account, your rate limits, your token budget. Recommendation by stage:

| Stage | Subagents | Tier |
|---|---|---|
| One Pager | 1 | **Pro** is fine |
| Pitch Deck | 10 parallel (5 waves of ~2) | **Max** strongly recommended |
| Final Thesis | 7 sequential with debate | **Pro** workable, **Max** smoother |

The Pitch Deck stage is the bottleneck — it fans out 10 specialist subagents, and Pro-tier accounts will hit usage limits mid-run. If you're on Pro and want to try anyway, generate One Pagers first; only spend Pitch Deck/Final Thesis budget on tickers that pass.

## What you get

Three reports per ticker, gated:

1. **One Pager** — quick screen, pass/fail.
2. **Pitch Deck** — 10-section research case (compounding, capital efficiency, capital allocation, resilience, valuation).
3. **Final Thesis** — conviction-level analysis with adversarial debate and a trade plan.

Each stage gates the next: you approve the prior verdict before the next runs.

## How it works

Thesis CLI is a thin orchestrator around Claude Code subagents:

- A skill (`/analyze TICKER`) kicks off the pipeline.
- The CLI fetches a canonical DataPacket from the hosted Thesis Data API using your free account API key.
- Local scripts slice the DataPacket for each agent, fetch and extract SEC filing sections, and load bundled transcripts from `./transcripts/`.
- Claude Code subagents run locally using your Claude Code subscription.
- Python renders the result to a PDF and DOCX, written to `~/thesis/reports/{TICKER}/`.

Your subscription, your machine, your reports.

## Data sources

- **Thesis Data API** — canonical DataPacket for prices, estimates, peer quotes, dividend history, and financial data.
- **SEC EDGAR** — public filing sections fetched and extracted locally for the agents.
- **Bundled transcripts** — earnings call transcripts for ~492 of the S&P 500 (~72 MB) ship in the repo at `./transcripts/`. No setup.
- **Alpha Vantage** — optional transcript fallback only if you supply an Alpha Vantage key in your environment.

## Privacy

- No telemetry, no analytics.
- Thesis API receives the ticker symbol and returns a DataPacket. Reports and Claude Code agent execution stay local.
- Network calls during a run: Thesis Data API (canonical DataPacket), SEC EDGAR (public filing sections), Anthropic (LLM via your Claude Code subscription), and optional Alpha Vantage transcript fallback if you configured a key.
- Reports and scratch state stay on your machine in `~/thesis/`.
- Optional connected mode (Phase 4, future) lets you push reports to an account at thesis-investing.com — opt-in per report.

See [PRIVACY.md](PRIVACY.md) for the full breakdown.

```

    |
    v
One Pager (1 subagent) ---- PASS? ----+
                                       v
Pitch Deck (10 subagents, 5 waves) ---- verdict?
                                       v
Final Thesis (7 subagents, with debate)
                                       v
                          ~/thesis/reports/{TICKER}/
                              one-pager.pdf
                              pitch-deck.pdf
                              final-thesis.pdf
```

## Philosophy

Buffett-flavored value investing. Public-domain methodology references: Buffett, Graham, Lynch, Munger. Scoring uses the 4-pillar Thesis Score (Compounding / Capital Efficiency / Capital Allocation / Resilience).
