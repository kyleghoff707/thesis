<objective>
Create a data quality checkpoint script and integrate it into the SKILL.md pipeline between data assembly and agent dispatch.

Purpose: Agents currently receive incomplete data silently. A checkpoint between data assembly (Step 2.5) and PSR dispatch (Step 3) gives the PM visibility into data completeness, blocks dispatch on critical failures, and allows gap-filling via pasted text or file paths. This is the last guardrail before agents start expensive API calls (per D-11, D-12, D-13).

Output: Standalone `data-quality-checkpoint.js` that reads DataPacket + filings-md/ and outputs structured JSON summary, tests for field classification logic, and SKILL.md updated with Step 2.6 checkpoint.
</objective>

    ```javascript
    #!/usr/bin/env node
    // CLI: node --loader ./scripts/node-esm-loader.js scripts/data-quality-checkpoint.js TICKER
    // Reads DataPacket + filings-md/ and outputs a structured quality report.
    // Exits 0 if can proceed, exits 1 if critical fields missing.
    // Output: JSON to stdout with { canProceed, summary, criticalMissing, warnings, filingQuality }
    ```

    1. Define field classification constants:
       ```javascript
       export const CRITICAL_FIELDS = ['companyInfo', 'financials', 'filings'];
       export const IMPORTANT_FIELDS = ['growthRates', 'returnMetrics', 'fcf', 'ruleOneScore', 'ttm'];
       export const NICE_TO_HAVE_FIELDS = [
         'analystEstimates', 'gurus', 'insiders', 'compensation',
         'peers', 'peerMetrics', 'events', 'prices',
         'transcriptAvailability', 'currentPrice', 'keyMetrics',
         'debtMetrics', 'caveats',
       ];
       ```

    2. Create `classifyField(fieldName)` function:
       ```javascript
       export function classifyField(fieldName) {
         if (CRITICAL_FIELDS.includes(fieldName)) return 'critical';
         if (IMPORTANT_FIELDS.includes(fieldName)) return 'important';
         if (NICE_TO_HAVE_FIELDS.includes(fieldName)) return 'nice-to-have';
         return 'unknown';
       }
       ```

    3. Create `assessDataPacket(dataPacket)` function:
       - Iterate all classified fields
       - Check if value is null/undefined
       - Return `{ canProceed: boolean, populated: string[], criticalMissing: string[], importantMissing: string[], warnings: string[], fieldCount: { total, populated, missing } }`
       - `canProceed` is false if ANY critical field is null

    4. Create `assessFilings(filingsDir)` function:
       - Read filings-md/ directory with `readdirSync`
       - Parse each .json file, count sections per filing
       - Return `{ complete: boolean, files: [{ filename, form, date, sectionCount, sections: string[] }], tenKCount, tenQCount, totalSections }`
       - `complete` is true if tenKCount >= 1 AND each 10-K file has >= 3 sections

    5. Main function:
       - Read data-packet.json from `.thes1s/reports/{TICKER}/`
       - Read filings-md/ directory
       - Call assessDataPacket and assessFilings
       - Print formatted summary table to stderr (human-readable)
       - Print JSON result to stdout (machine-readable for SKILL.md)
       - Exit 0 if canProceed, exit 1 if blocked

    6. Summary table format (printed to stderr):
       ```
       ═══════════════════════════════════════════════
       DATA QUALITY CHECKPOINT — {TICKER}
       ═══════════════════════════════════════════════

       DataPacket Fields: {populated}/{total}
       ───────────────────────────────────────────────
       CRITICAL:
         ✓ companyInfo         Apple Inc.
         ✓ financials          13 years
         ✓ filings             42 filings
       IMPORTANT:
         ✓ growthRates         populated
         ✗ ttm                 MISSING
       NICE-TO-HAVE:
         ✓ gurus               5 gurus hold AAPL
         ✗ analystEstimates    MISSING (finviz fallback failed)

       Filing Pre-Processing: {tenKCount} 10-Ks, {tenQCount} 10-Qs
       ───────────────────────────────────────────────
         10-K-2024-09-15.json  4 sections (Business, Risk Factors, MD&A, Financial Statements)
         10-Q-2024-07-30.json  3 sections (MD&A, Financial Statements, Risk Factors)
         ...

       ═══════════════════════════════════════════════
       ```
