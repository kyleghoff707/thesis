**6. Context assembly functions** (per RESEARCH.md Pattern 4):
- `loadAgentConfig(role)` — reads `agents/{role}/config.json`, returns parsed JSON. On error, throws with descriptive message.
- `loadAgentPrompt(role)` — reads `agents/{role}/prompt.md`, returns string.
- `loadCurriculum(curriculumPaths)` — reads each path (resolved from project root), joins with `\n\n---\n\n`. Missing files get `[Curriculum file not found: {path}]` placeholder.
- `sliceDataPacket(dataPacket, sliceKeys)` — if sliceKeys is null/empty, returns `{ ticker: dataPacket.ticker, caveats: dataPacket.caveats }`. Otherwise copies only the specified keys plus ticker and caveats.
- `buildUserMessage(dataSlice, options)` — assembles user message parts:
  - `## DataPacket\n\n` + JSON.stringify(dataSlice, null, 2) in a code fence
  - If `options.sectionAssignment`: `## Assignment\n\n{sectionAssignment}`
  - If `options.priorSections`: `## Prior Section Findings\n\n{summaries}`
  - Parts joined with `\n\n---\n\n`

**7. Web search URL extraction** (per RESEARCH.md Pattern 2):
- `extractWebSearchURLs(response)` — iterates `response.content`, for each block with `type === 'web_search_tool_result'`, iterates its `content` array, pushes `{ url, title, pageAge: result.page_age }` for each `web_search_result`. Returns the array.

**8. Citation enrichment** (per RESEARCH.md Pattern 2 + FIX-02):
- `enrichCitationsWithURLs(section, webSearchURLs)` — for each citation in `section.citations`:
  - Skip if `citation.url` already exists
  - Skip if `citation.source === 'DataPacket'` or `citation.ref?.startsWith('dataPacket.')`
  - Try to match by domain: `new URL(ws.url).hostname.replace('www.', '')` against `citation.source.toLowerCase()`
  - Also try title substring match: first 20 chars of `ws.title.toLowerCase()` against source
  - If match found, set `citation.url = match.url`

**9. Cost calculation** (per RESEARCH.md Code Example):
- `buildUsage(apiUsage, model)` — extracts `input_tokens`, `output_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`, `server_tool_use.web_search_requests` from the usage object. Computes cost using PRICING table. Returns `{ inputTokens, outputTokens, cacheRead, cacheWrite, webSearches, cost }`.

**10. Sleep helper:**
```javascript
const sleep = (ms) => new Promise(r => setTimeout(r, ms));
```

**11. dispatchWithRetry** (per RESEARCH.md Pattern 3):
- Accepts `callFn` (async function that accepts optional override options and returns API response) and `agentRole` string.
- Wraps in try/catch.
- On success: check `stop_reason`. If `"max_tokens"` — retry once with `{ maxTokens: 32768 }`. If still not `"end_turn"`, return `{ result: null, error: 'Truncated after retry', response }`. If `"refusal"` — return `{ result: null, error: 'Agent refused request (safety filter)', response }`. If `"end_turn"` — return `{ result: response.parsed_output, error: null, response }`.
- On catch: if `err.status === 429` — parse `retry-after` header (default 30s), sleep, retry once. If `err.status >= 500` — sleep 10s, retry once. If `err.status === 400` or other — return `{ result: null, error: '{status}: {message}' }`.

**12. Main dispatchAgent function** (per D-04, D-05, D-06):
```javascript
export async function dispatchAgent(agentRole, dataPacket, options = {}) {
```
Steps:
1. Record `startTime = Date.now()`
2. Load agent config, prompt, curriculum (including universalContext files if `config.universalContext === true`), slice DataPacket
3. Resolve model via MODEL_MAP (default to sonnet)
4. Build tools array — include `{ type: 'web_search_20250305', name: 'web_search', max_uses: options.maxSearches || 5 }` (enabled for all agents per RESEARCH.md recommendation)
5. Build system message: concatenate universal context + prompt + curriculum with `\n\n---\n\n` separator
6. Build user message via `buildUserMessage(dataSlice, options)`
7. Define `callFn` that takes optional overrides and calls `client.messages.parse()` with model, max_tokens (options.maxTokens || 16384), system, messages, tools, output_config
8. Call `dispatchWithRetry(callFn, agentRole)`
9. If error: return `{ section: null, usage: buildUsage(retryResult.response?.usage || {}, model), webSearches: [], model, stopReason: retryResult.response?.stop_reason || 'error', duration: Date.now() - startTime, error: retryResult.error }`
10. Process parsed_output: `JSON.parse(section.data)` if string (per D-06), extract web search URLs, enrich citations, overwrite tokenCost and modelUsed
11. Return `{ section, usage: buildUsage(response.usage, model), webSearches, model, stopReason: response.stop_reason, duration: Date.now() - startTime, error: null }`
