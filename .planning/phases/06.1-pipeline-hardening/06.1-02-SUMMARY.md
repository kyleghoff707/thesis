## Decisions Made
- Async executor: `createToolExecutor` returns an async function. All existing synchronous tools still work because `await syncValue` resolves immediately. The change is backward-compatible.
- Section boundary detection: Uses heading-level matching rather than a hardcoded list of next-item patterns. This handles PART I/II boundaries correctly (# PART vs ## Item).
- Transcript topic filtering: Splits transcript text on speaker block markers (`**Name:**`) rather than line-by-line. This preserves full speaker passages as atomic units.
- Alpha Vantage fallback: When Finnhub is unavailable, `getTranscriptExcerptImpl` passes `{ id: null }` to `fetchTranscript`, which triggers the Alpha Vantage fallback path automatically.
