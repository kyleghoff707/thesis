    **Per D-04 (pre-process filings to markdown before agent dispatch):**

    **1. Create src/engines/filingSections.js:**

    This module extracts specific sections from 10-K/10-Q markdown text.

    Export a `SECTION_MAP` constant mapping human-readable section names to regex patterns:
    ```javascript
    export const SECTION_MAP = {
      'Business': /^#{1,3}\s*(?:Item\s*1[.:]\s*)?Business/im,
      'Risk Factors': /^#{1,3}\s*(?:Item\s*1A[.:]\s*)?Risk\s*Factors/im,
      'MD&A': /^#{1,3}\s*(?:Item\s*7[.:]\s*)?Management['']?s?\s*Discussion/im,
      'Financial Statements': /^#{1,3}\s*(?:Item\s*8[.:]\s*)?Financial\s*Statements/im,
      'Controls': /^#{1,3}\s*(?:Item\s*9A[.:]\s*)?Controls/im,
      'Properties': /^#{1,3}\s*(?:Item\s*2[.:]\s*)?Properties/im,
      'Legal': /^#{1,3}\s*(?:Item\s*3[.:]\s*)?Legal/im,
      'Executive Compensation': /^#{1,3}\s*(?:Item\s*11[.:]\s*)?Executive\s*Comp/im,
      'Market Risk': /^#{1,3}\s*(?:Item\s*7A[.:]\s*)?Quantitative.*Market\s*Risk/im,
    };
    ```

    Export `function extractSection(markdown, sectionName)`:
    - Look up `sectionName` in `SECTION_MAP` (case-insensitive matching)
    - If not found, try a fuzzy match: `new RegExp(sectionName.replace(/\s+/g, '\\s+'), 'im')`
    - Find the start position of the matching header
    - Find the end position: the next header at the same or higher level (e.g., next `## Item` or `# Item`)
    - Return the substring between start and end
    - If no match found, return null (not empty string — caller can detect and fall back to full markdown)
    - If match found but section is very short (< 100 chars), return null (likely a false header match)

    Export `function extractAllSections(markdown)`:
    - Iterate over SECTION_MAP, extract each section
    - Return object: `{ 'Business': '...', 'Risk Factors': '...', ... }` (null values omitted)

    **2. Replace stubs in toolbox.js:**

    The `createToolExecutor(dataPacket)` function returns a closure. The closure currently calls `readFilingSectionStub` and `getTranscriptExcerptStub`. Replace these with async implementations.

    **IMPORTANT:** The tool executor must become async. Change the `switch` block in `createToolExecutor` so all `case` branches use `await`. The returned executor function signature changes from `(toolName, input) => result` to `async (toolName, input) => result`. This is a safe change because Claude's tool_use API handles async tool execution.

    **readFilingSection implementation:**
    ```javascript
    case 'readFilingSection':
      return await readFilingSectionImpl(dataPacket, input);
    ```

    Create `async function readFilingSectionImpl(dataPacket, { form, section, year })`:
    - Get the filing from `dataPacket.filings` matching `form` and optionally `year` (if no year, use most recent)
    - If no matching filing found, return `{ available: false, message: 'No ${form} filing found${year ? " for " + year : ""}' }`
    - Get CIK from `dataPacket.companyInfo.cik`
    - Call `fetchFilingMarkdown(cik, filing.accessionNumber, filing.primaryDocument)` to get the full markdown
    - Call `extractSection(markdown, section)` from filingSections.js
    - If extractSection returns null, return the full markdown (truncated to first 50,000 chars with a note)
    - Return `{ available: true, section, form, year: filing.filingDate.slice(0, 4), content: extractedText, charCount: extractedText.length }`

    Add imports at top of toolbox.js:
    ```javascript
    import { fetchFilingMarkdown } from './filingMarkdown.js';
    import { extractSection } from './filingSections.js';
    import { fetchTranscript } from './transcripts.js';
    ```

    **getTranscriptExcerpt implementation:**
    ```javascript
    case 'getTranscriptExcerpt':
      return await getTranscriptExcerptImpl(dataPacket, input);
    ```

    Create `async function getTranscriptExcerptImpl(dataPacket, { quarter, topic })`:
    - Parse quarter string (e.g., "Q4 2024") into quarter number and year
    - Call `fetchTranscript(dataPacket.ticker, quarterNum, year)` from transcripts.js
    - If transcript not found, return `{ available: false, message: 'Transcript not available for ${quarter}' }`
    - If no topic specified, return the full transcript content (truncated to 30,000 chars)
    - If topic specified, search through speaker entries for mentions of the topic (case-insensitive substring match)
    - Return matching passages: `{ available: true, quarter, topic, passages: [...matchingEntries], totalPassages: count }`
