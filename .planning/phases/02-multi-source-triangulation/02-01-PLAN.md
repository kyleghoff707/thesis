<objective>
Build three data collectors (FMP, SimFin, mstarpy) that each fetch annual financial statements for a given ticker, normalize them to the canonical field format using per-source field mappings, and cache responses to disk with 7-day TTL.

Purpose: These collectors are the data acquisition layer for the triangulation engine. Each produces data in the same canonical shape (`{ income: {year: {field: value}}, balance: {...}, cashFlow: {...} }`) so the consensus engine (Plan 02) can compare them.

Output: 3 collector modules, 1 shared cache utility, 1 Python pre-fetch script, extended field-mapping.json with `_sources` section, 3 test files.
</objective>
