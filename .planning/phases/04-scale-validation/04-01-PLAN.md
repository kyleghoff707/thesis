<objective>
Build the S&P 500 FMP comparison infrastructure: a cached ticker list, batch FMP data fetcher, tiered field comparator, reporter, and orchestrator script.

Purpose: This is the foundation for all Phase 4 validation. Without this infrastructure, we cannot compare our engine output against FMP at S&P 500 scale or identify which failures are Tier 1 (scoring-critical) vs Tier 2/3 (display/expanded).

Output: Five new files that together provide a `node validation/scripts/compare-sp500-fmp.mjs` command that fetches FMP data for all 503 S&P 500 companies, compares against the XBRL engine, and produces tiered accuracy reports (console + JSON).
</objective>

**1. `validation/scripts/fetch-sp500-fmp.mjs`** — Standalone batch FMP data fetcher.

Follow the exact pattern from `coverage-audit.js` lines 214-250: load HTML, `$('table.wikitable').first().find('tbody tr')`, extract first `td` cell, `.replace('.', '-')` for tickers like BRK.B -> BRK-B.

- For each ticker, call `fetchFmpData(ticker, { apiKey, cacheDir, cacheTtlMs: 7*24*60*60*1000, fieldMappingPath })` from `fmp-collector.mjs`. **2. `validation/scripts/lib/sp500-fmp-comparator.mjs`** — Tiered field comparison logic.

- Export `FIELD_TIERS` constant: duplicate the 85-field tier map from `tickerAudit.js` lines 502-532 (22 Tier 1, 30 Tier 2, 33 Tier 3). These use ENGINE field names (e.g., `equity`, `assets`, `cash`), not canonical names.
- Export `function compareFmpToEngine(ticker, fmpData, engineData)`:
  - Determine overlapping years: intersection of `Object.keys(fmpData.income)` and `engineData.years`.
  - For each statement type (`income`, `balance`, `cashFlow`):
    - For each overlapping year:
      - For each field in the FMP data for that year:
        - Resolve canonical FMP field name to engine field name using `resolveFieldName(canonical)` from `field-alias-map.mjs`.
        - Look up engine value: `engineData[stmtKey][year][engineFieldName]`.
        - Look up tier: `FIELD_TIERS[engineFieldName] || 0` (0 = untiered/unmapped).
        - Compare using `compareField(fmpValue, engineValue, 1, tierToTolerance(tier))` from `comparator.mjs`. The sign multiplier is always 1 because FMP data has ALREADY been sign-normalized at fetch time by `fmp-collector.mjs`.
        - Tier-to-tolerance mapping: Tier 1 -> `'exact'` (1%), Tier 2 -> `'close'` (5%), Tier 3 -> `'approximate'` (10%), untiered -> `'informational'`.
        - Push result: `{ field: engineFieldName, canonicalField: canonical, statement: stmtKey, year, tier, status, pct, expected: fmpValue, actual: engineValue }`.
  - Skip if `fmpData` or `engineData` is null (return `{ ticker, status: 'NO_DATA', results: [] }`).
  - Handle RACE (EUR filer): if `EUR_COMPANIES.has(ticker)`, return `{ ticker, status: 'SKIP_EUR', results: [] }`. Import `EUR_COMPANIES` from `comparator.mjs`.
  - Return `{ ticker, status: 'OK', yearsCompared: overlappingYears.length, results: Array }`.

- Export `function tierToTolerance(tier)`:
  - `1 -> 'exact'`, `2 -> 'close'`, `3 -> 'approximate'`, default -> `'informational'`.
