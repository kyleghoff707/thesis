  <action>
Execute the iterative fix+validate cycle following Phase 3's proven pattern. Each iteration:

**Iteration Loop:**

1. **Identify highest-impact Tier 1 fix**: From the JSON report's `topTier1Failures` and the outlier investigation, pick the Tier 1 failure pattern that affects the MOST companies and is clearly an engine bug (not methodology diff).

2. **Apply fix in edgarFinancials.js or industryOverlays.js**: Make the targeted change. Only fix what FMP confirms as wrong per D-04. DO NOT chase:
   - Tier 2 or Tier 3 disagreements
   - Methodology diffs (FMP calculates differently)
   - Fields where our engine value is arguably correct and FMP's is the outlier

3. **Rebuild engine bundle**: `node validation/scripts/bundle.mjs`

4. **MS regression gate**: `node validation/scripts/compare-morningstar.mjs`
   - Check the overall accuracy in the console output. It MUST remain >= 94.0%.
   - If it drops below 94.0%, REVERT the fix immediately and document why.

5. **S&P 500 progress check**: `node validation/scripts/compare-sp500-fmp.mjs`
   - Compare new Tier 1 accuracy against previous iteration.
   - Record the delta.

6. **Stabilization check**: Stop iterating when BOTH conditions are met:
   - Tier 1 accuracy improvement < 0.5% from previous iteration
   - No Tier 1 failure pattern affects 5+ companies with a clear fix

**Important constraints:**
- The RESEARCH notes that FMP fiscal year uses `fiscalYear` field — if you see systematic 1-year offsets for non-December FY companies (NKE, WMT, FDX, COST), this is a fiscal year alignment issue, not an engine bug. Document it but don't "fix" it by shifting engine data.
- Financial sector fixes (per D-06) should go in industryOverlays.js. If FMP confirms our bank/REIT/insurance overlay values are wrong for specific fields, fix the overlay tags. If FMP and our engine agree but MS was different, the overlay is correct — document this finding.
- Keep each fix atomic: one fix per iteration, verified before moving to the next. This prevents fix interactions that are hard to debug.

**After all iterations:**
- Run final `node validation/scripts/compare-sp500-fmp.mjs` to produce the definitive sp500-fmp-accuracy.json.
- Run final `node validation/scripts/compare-morningstar.mjs` to confirm MS baseline holds.
- Update the outlier investigation document with any new findings from the fix cycle.

**If no fixable Tier 1 bugs are found (accuracy is already good):**
- Document this finding: "Initial S&P 500 Tier 1 accuracy is X.X%. No systematic Tier 1 failure patterns affect 5+ companies with clear engine fixes. Phase 3 fixes generalized well to S&P 500 scale."
- Skip further iterations and proceed to the checkpoint.
