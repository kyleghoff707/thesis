| Property | Value |
|----------|-------|

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage in This Phase |
|-------|-------|---------------------|
| xs | 4px | Gap between verdict badge icon and label, checklist item number min-width alignment |
| sm | 8px | Segmented bar top margin, gap between header badges, row gap between checklist items (padding: '8px 0'), exchange row padding vertical (padding: '8px 12px') |
| md | 16px | Section card padding (16px 20px), aggregate bar bottom margin, debate tab content margin-bottom |
| lg | 20px | Card horizontal padding (per SectionRenderer convention: `padding: '16px 20px'`) |
| xl | 24px | Number circle size (24x24px), approval bar margin-top |
| tab | 20px | Debate tab button horizontal padding |

Exceptions:
- SectionRenderer card uses `padding: '16px 20px'` -- not a pure 16px square. Both renderers MUST match this exactly.
- `scrollMarginTop: 160` on card wrapper -- inherited from SectionRenderer, not a general spacing token.
- `marginBottom: -8` on QualityBadge overlay -- inherited from Phase 20, applied outside the renderers by FullStory.jsx.

Source: SectionRenderer.jsx lines 96-103, RESEARCH.md Pattern 3.

### Accent Reservation (Explicit)

Accent (C.accent) is reserved for ONLY these elements in this phase:
1. Rebuttal tab text color (active state)
2. Rebuttal tab bottom-border indicator (active state)
3. Rebuttal content area left-border (3px)
4. REVIEW verdict badge background (existing, not in this phase)

Accent is NOT used for: checklist items, aggregate bars, debate Bull/Bear/Judge elements, or general interactive affordances.

## Interaction Contracts

### Checklist Item Expand/Collapse

| Property | Value |
|----------|-------|
| Trigger | Click anywhere on the item row (verdict badge, number, question text, confidence, chevron) |
| Keyboard | Enter or Space on focused row |
| Default state | All items collapsed (D-02) |
| Toggle mechanism | `useState(new Set())` tracking expanded item numbers |
| Expand indicator | Right-pointing triangle (&#9654;) rotates 90deg clockwise when expanded |
| Rotation transition | `transition: 'transform 0.2s'` |
| Expanded content | Evidence paragraph appears below the row with `padding: '8px 0 4px 44px'` left indent |
| Role attribute | `role="button"` + `tabIndex={0}` on the clickable row div |
| No animation on content | Content appears/disappears instantly (no height animation). CollapsibleSection is overkill for individual rows. |

Source: CONTEXT.md D-01, D-02, RESEARCH.md Pattern 4.

### Debate Tab Switching

| Property | Value |
|----------|-------|
| Trigger | Click on tab button (Bull, Bear, Rebuttal, Judge) |
| Default tab | Bull (first tab) |
| State management | `useState('bull')` local to DebateRenderer |
| Tab indicator | 2px bottom border in role color on active tab, transparent on inactive |
| Tab text | fontWeight 700 when active, 400 when inactive |
| Tab text color | Role color when active, C.textMuted when inactive |
| Content transition | Instant swap -- no fade or slide animation |
| Active content area | Left border 3px solid in role color, padding-left 16px |
| No URL changes | D-07: tab state is component-local, no router integration |

Source: CONTEXT.md D-06, D-07, D-08, RESEARCH.md Pattern 5.

### Exchange Row Expand/Collapse

| Property | Value |
|----------|-------|
| Trigger | Click on exchange row |
| Default state | All exchanges collapsed |
| Toggle mechanism | Same `useState(new Set())` pattern as checklist items |
| Collapsed view | Bull strength badge - verdict text (centered) - Bear strength badge + topic below |
| Expanded view | Adds reasoning paragraph below topic, separated by 1px border-top |

Source: CONTEXT.md D-13, RESEARCH.md Code Examples (Judge Exchange Row).

### Debate Point Expand/Collapse (Bull/Bear/Rebuttal Tabs)

| Property | Value |
|----------|-------|
| Trigger | Click on point row |
| Default state | All points collapsed |
| Collapsed view | Point text (one line or truncated) + badge if applicable |
| Expanded view | Full evidence paragraph, sources list (Bear), strength/honest indicators (Rebuttal) |

```
+--------------------------------------------------+
| [N] Section Title          [VerdictBadge] [Conf]  |  <- Section header (replicate SectionRenderer)
|--------------------------------------------------|
| [====green====][=yellow=][red]                    |  <- Segmented aggregate bar (8px height)

|--------------------------------------------------|
| [PASS] #1  Can you describe the business...  [>] |  <- Checklist item row (collapsed)
|-------------------------------------------  -----|
| [FAIL] #2  Do you understand the product... [>]  |
|-------------------------------------------  -----|
```

## Copywriting Contract

| Element | Copy |
|---------|------|
| Aggregate score text | `"{passCount} PASS · {partialCount} PARTIAL · {failCount} FAIL"` -- middot separator, all-caps verdict labels |
| Tab labels | `Bull` / `Bear` / `Rebuttal` / `Judge` -- title case, no extra text |
| Bull tab header | Render `debateOutputs.bull.content.overallThesis` verbatim as-is |
| Bear tab header | Render `debateOutputs.bear.content.overallBearCase` verbatim as-is |
| Honest admission label | `"Point conceded"` -- shown when `honest === false` on a rebuttal item |
| Exchange verdict labels | Render verbatim from data: `"Resolved"`, `"Unresolved"`, `"Strong Bull"`, `"Strong Bear"` |
| Judge verdict heading | `"Overall Verdict"` -- 12px/700, above DirectionBadge |
| Investment implication label | `"Investment Implication"` -- 12px/700 label, followed by implication text |
| Empty debate state heading | `"Debate Not Available"` |
| Empty debate state body | `"Adversarial debate data has not been generated for this report."` |
| Empty checklist state heading | `"Checklist Not Available"` |
| Empty checklist state body | `"Checklist data has not been generated for this section."` |
| Source section label (Bull points) | Render `sourceSection` value as small muted text below evidence (e.g., `"Source: S2: Meaning Checklist"`) |
| Severity badge labels | `"THESIS KILLER"` / `"SIGNIFICANT"` -- uppercase, derived from data enum values |
| Strength badge labels | `"STRONG"` / `"MODERATE"` / `"WEAK"` -- uppercase |

No destructive actions exist in this phase. No primary CTA exists -- these are read-only display renderers.

## State Management

| State | Location | Type | Default |
|-------|----------|------|---------|
| Expanded checklist items | ChecklistRenderer | `useState(new Set())` | Empty set (all collapsed) |
| Active debate tab | DebateRenderer | `useState('bull')` | `'bull'` |
| Expanded debate points | Each tab sub-component | `useState(new Set())` | Empty set (all collapsed) |

## Accessibility

| Element | Requirement |
|---------|-------------|
| Checklist item row | `role="button"`, `tabIndex={0}`, keyboard Enter/Space triggers toggle |
| Debate tab button | Native `<button>` element -- inherently focusable and keyboard-accessible |

## Debate Tab Key-to-Data Mapping

Prevents Pitfall 3 (tab key mismatch with debateOutputs keys):

| Tab Key | debateOutputs Key | Content Path |
|---------|-------------------|--------------|
| `bull` | `debateOutputs.bull` | `.content.overallThesis`, `.content.thesisPoints[]` |
| `bear` | `debateOutputs.bear` | `.content.overallBearCase`, `.content.inversions[]` |
| `rebuttal` | `debateOutputs.bull_rebuttal` | `.content.rebuttals[]` |
| `judge` | `debateOutputs.judge` | `.content.exchanges[]`, `.content.overallVerdict` |

The `rebuttal` tab maps to `bull_rebuttal` in the data. This MUST be explicit in the code -- do not assume tab key matches data key.

Source: RESEARCH.md Pitfall 3.

## Empty/Error States

### Empty Checklist

When `section.data?.items` is null, undefined, or empty array:
- Show section header (number + title + verdict + confidence) normally
- Replace content area with centered muted text: "Checklist data has not been generated for this section." at 13px, C.textMuted, `textAlign: 'center'`, `padding: '32px 0'`

### Empty Debate

When `debateOutputs` is null or undefined:
- Show section header normally
- Replace content area with centered muted text: "Adversarial debate data has not been generated for this report." at 13px, C.textMuted, `textAlign: 'center'`, `padding: '32px 0'`

### Missing Individual Debate Role

When a specific role key (e.g., `debateOutputs.bear`) is missing:
- Tab still appears in the tab bar (maintains 4-tab layout)
- Content area shows: "Data for this debate step is not available." at 13px, C.textMuted, centered

Source: RESEARCH.md Pitfall 4.
