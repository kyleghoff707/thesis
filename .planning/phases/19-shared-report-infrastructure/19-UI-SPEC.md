## StageNavBar -- Detailed Spec

### Layout
- **Position:** Below company header, above report content. Rendered inside the report route layout, not in Layout.jsx
- **Height:** ~40px (10px top padding + 13px text + 10px bottom padding + 2px border + 1px border-bottom = ~36-40px)
- **Width:** Full content width (flex row, no max-width constraint -- inherits from parent container)
- **Bottom border:** `1px solid C.border` spanning full width
- **Bottom margin:** 24px gap before report content begins

### Tab Buttons (3 tabs)

| Tab | Label | Gate Condition |
|-----|-------|----------------|
| 1 | One Pager | Always unlocked |
| 2 | Pitch Deck | Locked until `stageApprovals.onePager === 'approved'` |
| 3 | Full Story | Locked until `stageApprovals.pitchDeck === 'approved'` |

### Tab States

| State | Font Weight | Text Color | Border Bottom | Opacity | Cursor |
|-------|-------------|------------|---------------|---------|--------|
| Active | 600 | `C.accent` | `2px solid C.accent` | 1 | `pointer` |
| Inactive (unlocked) | 400 | `C.text` | `2px solid transparent` | 1 | `pointer` |
| Locked | 400 | `C.textMuted` | `2px solid transparent` | 0.5 | `not-allowed` |

### Lock Icon (for locked tabs)
- **Size:** 12x12px inline SVG
- **Color:** `C.textMuted`
- **Position:** Left of tab label, 6px gap
- **Icon:** Padlock (closed lock shape -- path-based SVG, not imported from a library)

### Tooltip (for locked tabs)
- **Trigger:** Hover on locked tab
- **Content:** "Approve One Pager to unlock Pitch Deck" or "Approve Pitch Deck to unlock Full Story"
- **Implementation:** Native `title` attribute on the button element (matches D-05 simplicity)

### Props Interface
```
StageNavBar({ stageApprovals })
```
- `stageApprovals`: `{ onePager: string|null, pitchDeck: string|null, fullStory: string|null }`
- Reads `id` from `useParams()`, current path from `useLocation()`, navigates via `useNavigate()`

**Source:** D-04, D-05, D-06 from CONTEXT.md. Toolbox.jsx tab styling pattern (lines 196-223).

### Citation Integration
- The custom `p` component scans string children for `[N]` patterns (where N is a digit sequence)
- When citations array is provided: splits text on `/\[\d+\]/` and interleaves `CitationTooltip` components via `renderTextWithCitations()` from `CitationTooltip.jsx`
- When no citations: renders paragraph text verbatim

### Theme Reactivity
- `makeComponents(citations, onCitationClick)` is called inside the render function (not memoized, not at module level) to read current `C` palette values after theme toggle

### Props Interface
```
ReportMarkdown({ content, citations, onCitationClick })
```
- `content`: Markdown string to render
- `citations`: Array of citation objects (optional)
- `onCitationClick`: Callback when citation is clicked (optional)

## useScrollSpy -- Hook Spec

### Interface
```javascript
const activeSection = useScrollSpy(sectionIds, {
  prefix: 'section-',    // DOM ID prefix
  threshold: 0.3,        // IntersectionObserver threshold
  topOffset: 100,        // Pixels from top to exclude (nav + stage bar)
});
```

### Behavior
- Creates IntersectionObserver with `rootMargin: -${topOffset}px 0px -60% 0px`
- On intersection: picks entry with highest `intersectionRatio`
- Strips `prefix` from element ID to return clean section key
- **Debouncing:** `requestAnimationFrame` wrapper in observer callback -- coalesces rapid intersection events to 1 state update per paint frame
- **Cleanup:** Disconnects observer and cancels pending animation frame on unmount or dependency change
- **Empty input:** Returns `null` when `sectionIds` is empty or undefined

### Default topOffset Values
- OnePager (without StageNavBar): `100` (52px nav + 48px buffer)
- PitchDeck/FullStory (with StageNavBar): `100` (52px nav + 40px StageNavBar + 8px buffer)

**Source:** D-07, D-08, D-09 from CONTEXT.md. RESEARCH.md Pattern 3. Existing OnePager.jsx lines 122-158.

## Interaction Contracts

### Sidebar Nav Click
1. User clicks a section name in the sticky sidebar
2. Page smooth-scrolls to the target section (`behavior: 'smooth'`)
3. Section is positioned below the nav bar + StageNavBar (via `scrollMarginTop: 160`)
4. Active section indicator updates to the clicked section

### Scroll Spy Update
1. User scrolls through report content
2. IntersectionObserver detects which section is most visible in the top 40% of viewport
3. `requestAnimationFrame` debounce coalesces updates to prevent flicker
4. Sidebar active indicator moves to the most-visible section
5. No more than 1 state update per animation frame (~16ms)

### StageNavBar Tab Click
1. User clicks an unlocked tab (e.g., "Pitch Deck")
2. `useNavigate` navigates to `/research/{id}/pitch-deck`
3. New report viewer component renders
4. StageNavBar remains visible with updated active state

### StageNavBar Locked Tab Click
1. User clicks a locked tab
2. Nothing happens (button is `disabled`)
3. Hover shows native tooltip explaining the gate requirement

### Theme Toggle
1. User toggles dark/light mode
2. `C` palette object mutates via `Object.assign`
3. All StageNavBar tabs, sidebar items, and ReportMarkdown content re-render with new colors
4. `makeComponents()` in ReportMarkdown is called fresh on each render (never memoized) to pick up new `C` values
