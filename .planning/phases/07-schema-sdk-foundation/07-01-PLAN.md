<objective>
Fix ReportSectionSchema for Claude API structured output compatibility by replacing z.looseObject({}) with z.string() in all API-facing fields, adding optional url to CitationSchema, and updating critic.js for backward compatibility.

Purpose: The Claude API requires additionalProperties: false on all objects in structured output schemas. z.looseObject({}) produces additionalProperties: true which gets transformed by the SDK into an empty-object-only constraint ({properties: {}, additionalProperties: false}). Replacing with z.string() sidesteps this entirely — the agent serializes flexible data as JSON strings, and the orchestrator parses after extraction.

Output: Modified schema file, new schema unit tests, updated critic.js with backward-compatible data handling, updated critic tests.
</objective>
