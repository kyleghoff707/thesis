## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, verdict dot margins |
| sm | 8px | Compact element spacing, nav item padding, badge gaps |
| md | 16px | Default card padding, section card internal padding, hero subdivisions |
| lg | 24px | Hero marginBottom, two-column layout gap, approval bar marginTop, section card marginBottom |
| xl | 32px | Page-level top/bottom padding for loading/error/empty states |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Sticky nav `top: 72px` (52px Layout nav + 8px buffer + 12px StageNavBar allowance) -- follows PitchDeck precedent
- `scrollMarginTop: 160px` on section anchors -- accounts for Layout header (52px) + StageNavBar (~40px) + sticky nav offset + buffer. Existing SectionRenderer value, do not override.
- Approval bar button padding: `12px 24px` -- follows PitchDeck precedent for comfortable click targets

Source: PitchDeck.jsx measured values, SectionRenderer.jsx line heights

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 13px | 400 (regular) | 1.6 |
| Label | 11px | 600 (semibold) | 1.4 |
| Heading | 14px | 700 (bold) | 1.3 |
| Display | 24px | 700 (bold) | 1.2 |

Usage mapping for this phase:
- **Display (24px/700):** Company name in hero header (matches PitchDeck hero)
- **Heading (14px/700):** Section title text within SectionRenderer section headers
- **Body (13px/400):** Narrative text, verdict rationale, summary blurb, stage label, approval bar description, gate check message, empty/error state text
- **Label (11px/600):** Generated timestamp, approval status indicator, quality badge labels, primarySourceInsights/searchesPerformed section headers (10px uppercase variant)

Additional type treatments used in this phase:
- **10px/700 uppercase, letterSpacing 0.04em:** Micro labels -- "Primary Source Insights", "Searches Performed", section subsection headers. Color: `C.textMuted`.
- **13px/700:** Ticker display in hero. Color: `C.accent`.
- **13px/600:** Stage label "Stage 3: Full Story", approval bar "Ready for approval" prefix, approve/reject button text.
- **15px/600:** Empty state heading "No Full Story generated yet".

Source: PitchDeck.jsx measured typography, OnePager.jsx patterns, SectionRenderer.jsx

## Interaction States

### Loading State

```
Container: flex, alignItems center, justifyContent center, height 40vh, gap 10
  Spinner component (existing)
  "Loading report..." -- 13px/400, C.textMuted
```

### Error State

```
Container: padding 20
  Error message: 13px/400, C.red
  Text: "{error message from hook}"
```

### Empty State (no report, not generating)

```
Container: flex column, alignItems center, justifyContent center, gap 8
  Heading: 15px/600, C.text -- "No Full Story generated yet"
  Body: 13px/400, C.textMuted -- "Run the Full Story pipeline for {ticker} to create one. The Pitch Deck must be approved first."
```

### Quality Data Missing State

When `quality` is null (older reports, quality check not run):
- Quality line in hero: omit entirely (do not show "Quality: --")
- Per-section QualityBadge: return null (badge simply absent from header row)
- No error, no placeholder -- graceful omission

### Scroll Spy Active State

Active section in sticky nav receives:
- `color: C.accent` (was `C.textSecondary`)
- `fontWeight: 600` (was `400`)
- `background: C.bgHover` (was `transparent`)
- `borderLeft: 3px solid C.accent` (was `3px solid transparent`)

Transition: `all 0.15s` for smooth state changes.

### Nav Click Behavior

Click on nav item scrolls corresponding section into view via `element.scrollIntoView({ behavior: 'smooth' })`. Section `id` attributes match SECTION_DEFS keys for scroll spy targeting.

### Approval Bar Interactions

- **Approve click:** Sets `stageApprovals.fullStory = 'approved'` via `updateReport`. Bar disappears. "Approved" label appears in hero Row 3.
- **Reject click:** Prompts for notes (window.prompt or inline input, follow PitchDeck pattern). Sets `stageApprovals.fullStory = 'rejected'` with notes. Bar disappears. "Rejected" label appears in hero Row 3.

Source: PitchDeck.jsx interaction patterns, OnePager.jsx loading/error/empty states

### Quality-to-Section Join

```javascript
// Build lookup map from quality.sections array
const qualityMap = {};
if (quality?.sections) {
  for (const qs of quality.sections) {
    qualityMap[qs.sectionKey] = qs;
  }
}
// Access: qualityMap['event_analysis']?.score, qualityMap['event_analysis']?.methodology?.score
```

### Hero Verdict Source

```javascript
// Direct read -- no computation, no aggregation (D-14)
const verdict = report?.debateOutputs?.judge?.content?.overallVerdict;
// verdict.direction: 'Bear' | 'Bull' | 'Neutral'
// verdict.summary: string (1-2 sentence excerpt for hero blurb)
// verdict.investmentImplication: string (actionable guidance for callout box)
```

### Company Name Fallback (Pitfall 3)

```javascript
// full-story-api.json does NOT have companyName -- use report from useResearch
const companyName = report?.companyName || fullStoryData?.ticker || '';
// full-story-api.json uses completedAt, NOT generatedAt
const timestamp = fullStoryData?.completedAt;
```
