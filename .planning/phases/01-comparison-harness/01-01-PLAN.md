    **comparator.mjs:**
    Extract and modularize the comparison logic from morningstarAccuracy.test.js lines 174-363. This module imports `resolveYearOffset` from fiscal-aligner.mjs and uses the field mapping structure from field-mapper.mjs.

    Implementation:
    1. Export `THRESHOLDS` constant: `{ exact: 0.01, close: 0.05, approximate: 0.10, relaxed: 0.20, informational: Infinity }`
    2. Export `FINANCIAL_SECTOR` constant: `new Set(['BRK-B', 'JPM', 'MET', 'WFC'])`
    3. Export `SPIN_OFF` constant: `{ EW: 2023, JNJ: 2023, T: 2022 }`
    4. Export `EUR_COMPANIES` constant: `new Set(['RACE'])`
    5. Export `compareField(msValue, thesisValue, sign, tolerance)`:
       - Compute `expected = sign * msValue`, `actual = thesisValue`
       - Both near-zero (abs < 1): MATCH with pct 0
       - Expected zero: MATCH if abs(actual) < 1,000,000, else DIFF
       - Otherwise: `pct = abs((actual - expected) / expected)`, compare against THRESHOLDS[tolerance]
       - Return `{ status, pct, expected, actual }` where status is MATCH, CLOSE, or DIFF
    6. Export `compareCompany(ticker, fixture, engineData, fieldMapping, options)`:
       - `options` can include `{ specialHandlers }` from field-mapper.mjs for intangibles/opIncome/accrued/taxRate
       - Call `resolveYearOffset(fixture, engineData)` to get FY offset
       - For each statement type (income, balance_sheet, cash_flow) and each mapped field:
         a. Get MS years from fixture.statements[stmtKey]
         b. For each MS year: compute edgarYear = msYear + offset
         c. Apply special field handlers (intangibles NET, operating income reported, accrued skip, tax rate scale) -- these are passed in from field-mapper to keep comparator pure
         d. Skip if msValue is null
         e. Skip pre-spin years for SPIN_OFF companies (status: SKIP_SPINOFF)
         f. Check if engine has data for edgarYear (MISSING_YEAR if not)
         g. Check if engine has field value (MISSING_FIELD if null)
         h. For FINANCIAL_SECTOR companies on revenues/total_debt/net_debt: override tolerance to "relaxed"
         i. Call compareField and push result
       - Return `{ ticker, offset, results }`

    The `compareCompany` function takes `specialHandlers` as an explicit dependency rather than hardcoding them -- this keeps the comparator testable with mock handlers and extensible for Phase 2 additional sources.
