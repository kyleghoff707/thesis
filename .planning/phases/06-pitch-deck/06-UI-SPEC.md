# Phase 6 -- UI Design Contract

> Visual and interaction contract for PitchDeck.jsx, 10 section sub-components, SensitivityTable.jsx, and delight features (deep-dive, industry cards, assumption tracker). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none -- inline styles with mutable `C` palette from `src/theme.js` |
| Icon library | Inline SVG (feather-style, 24x24 viewBox, strokeWidth 2, strokeLinecap round) |
| Font | Inter / system font stack (`-apple-system, BlinkMacSystemFont, 'Inter', sans-serif`) |

**Source:** Established codebase pattern (30+ components). No CSS files, no CSS-in-JS, no Tailwind, no shadcn.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, citation superscript margin |
| sm | 8px | Compact element spacing, badge gaps, nav item padding |
| md | 16px | Default element spacing, card padding, section margins |
| lg | 24px | Section padding, two-column gap, report header bottom margin |
| xl | 32px | Layout gaps between major areas |

Exceptions:
- Section card padding: `16px 20px` (matches SectionRenderer.jsx established pattern)

**Source:** Measured from existing SectionRenderer.jsx, OnePager.jsx, CollapsibleSection.jsx

## SensitivityTable.jsx -- Design Contract

### Purpose

Displays a 2D matrix varying two assumptions against each other, showing resulting buy prices for a single valuation method. Used in Section 10 (Valuation) with one table per enabled method (up to 4: MOS, PBT, Ten Cap, Equity Bond).

### Layout

```
+--------------------------------------------------+
|  MOS Buy Price Sensitivity                       |
|  Rows: FGR (%)  |  Columns: EPS ($)              |
+--------------------------------------------------+
|         | $5.00 | $5.50 | $6.00 | $6.50 | $7.00 |
|---------|-------|-------|-------|-------|-------|
|   8%    | $52   | $57   | $62   | $68   | $73   |
|  10%    | $68   | $75   | $82   | $89   | $96   |
|  12%    | $89   | $98   |$107*  |$116   |$125   |
|  14%    | $116  | $127  | $139  | $151  | $162  |
|  16%    | $150  | $165  | $180  | $195  | $211  |
+--------------------------------------------------+
* = current input values intersection
```

### Visual Rules

- **Title:** 16px / 700, C.text
- **Subtitle (axis labels):** 10px / 700, C.textSecondary
- **Column headers:** 10px / 700, C.textMuted, right-aligned, uppercase
- **Row headers:** 10px / 700, C.textMuted, left-aligned
- **Cell values:** 13px / 400, C.text, right-aligned, `fontVariantNumeric: 'tabular-nums'`
- **Current input intersection cell:** 13px / 700, C.accent, background C.accentLight, borderRadius 4px
- **Table border:** outer `1px solid C.border`, inner rows `1px solid C.borderLight`
- **Cell padding:** `8px 12px`
- **Cell color coding (MOS proximity):**

| Condition | Cell Background | Text Color |
|-----------|----------------|------------|
| Buy price < current price (undervalued) | `C.greenBg` | `C.green` |
| Buy price within 20% of current price | `C.yellowBg` | `C.yellow` |
| Buy price > 120% of current price (overvalued) | none (default) | `C.text` |

- **Container:** Wrapped in CollapsibleSection with badge showing the method's current buy price range
- **Spacing between tables:** 16px marginBottom per table, 24px before the group

### Props Interface

```js
SensitivityTable({
  title,          // "MOS Buy Price Sensitivity"
  rowLabel,       // "FGR (%)"
  colLabel,       // "EPS ($)"
  rowValues,      // [0.08, 0.10, 0.12, 0.14, 0.16]
  colValues,      // [5.00, 5.50, 6.00, 6.50, 7.00]
  computeCell,    // (rowVal, colVal) => number | null
  formatRow,      // (val) => "12%" -- row header formatter
  formatCol,      // (val) => "$6.00" -- column header formatter
  formatCell,     // (val) => "$107" -- cell value formatter
  currentRow,     // 0.12 -- highlight intersection
  currentCol,     // 6.00 -- highlight intersection
  currentPrice,   // 185.50 -- for MOS proximity coloring
})
```

## Interaction Contracts

### I-01: Section Collapsibility

Pitch Deck sections are rendered by SectionRenderer (same as One Pager) and are NOT individually collapsible. The 10 sections render as a vertical scroll within the content column. CollapsibleSection is used only for sub-groups within sections (e.g., the 4 sensitivity tables within Section 10).

**Rationale:** OnePager has 6 sections and does not collapse them. Pitch Deck has 10 -- still manageable as a scroll. The sticky nav provides fast jumping. Collapsing individual sections would hide context that the PM needs visible for cross-section review.

### I-02: Checkpoint Display

Checkpoints are a generation-time concept (terminal dialogue in the CC skill). In the React UI, checkpoint data is displayed as a summary block between phase groups. Each checkpoint shows:

- **Phase label:** "Phase 1: Business Fundamentals" -- 13px / 700, C.textSecondary
- **Data gaps found:** bulleted list (if any)
- **PM notes injected:** quoted text (if any)
- **Confidence snapshot:** per-section confidence at that point
- **Visual:** Thin horizontal rule with phase label centered, C.border, marginTop/marginBottom 24px

These are informational -- the PM already acted on them during generation. They serve as an audit trail.

### I-03: Approval Gate

Identical to OnePager.jsx approval bar pattern:
- Appears only when all 10 sections are rendered and generation is COMPLETE
- Two buttons: "Approve" (C.green bg, white text) and "Reject" (transparent bg, C.red border/text)
- Reject prompts for optional notes via `window.prompt()`
- Approval/rejection persists to `report.stageApprovals.pitchDeck`
- When approved, unlocks Stage 3 (Full Story)

### I-04: FGR Derivation Display

Section 10 (Valuation) includes an FGR derivation summary showing how the FGR Low/High range was determined. This is a read-only display of the 5-input workflow that happened during generation:

```
+---------------------------------------------------+
|  FGR Derivation                                    |
|  Final: 10% -- 14%                                 |
|---------------------------------------------------|
|  1. Historical Composite: 12.3%     [HIGH]        |
|  2. Market Relativity: +2.1% vs S&P [MEDIUM]      |
|  3. Company Guidance: 8-12%          [HIGH]        |
|  4. Industry CAGR: 9.5%             [MEDIUM]      |
|  5. Analyst Consensus: 11.2%         [HIGH]        |
+---------------------------------------------------+
```

- Wrapped in CollapsibleSection with title "FGR Derivation" and badge showing the range
- Each input: 13px / 400, C.text, with ConfidenceBadge inline
- Final range: 16px / 700, C.accent

### I-05: Active Section Tracking

IntersectionObserver-based scroll tracking (same as OnePager.jsx):
- Threshold: 0.3
- Root margin: `-80px 0px -60% 0px`
- Updates sticky nav active state in real-time
- Click on nav item triggers `scrollIntoView({ behavior: 'smooth' })`

### I-06: Deep Dive Interaction Flow (Phase 6D)

1. User reads a section and sees a specific claim they want explored
2. "Tell me more" text link appears next to notable claims (agent-marked)
3. Click opens the DeepDivePanel slide-out
4. Panel shows loading spinner while AI generates expanded analysis
5. Result renders with citations and related section links
6. User closes panel and returns to reading

### I-07: Assumption Tracker Interaction Flow (Phase 6D)

1. "Assumptions (N)" button visible in report hero
2. Click opens AssumptionTracker sidebar
3. Sidebar lists all key assumptions with confidence bars
4. If assumption is changed by PM (future feature), affected sections show yellow warning dots
5. Phase 6D: read-only display. Edit capability deferred.

## Accessibility Notes

- All interactive elements (nav items, buttons, collapsible triggers) must be keyboard-focusable
- Verdict badges use both color AND icon + text label (not color alone)
- Confidence badges use both color AND text label
- Sensitivity table cells use color as enhancement, not sole indicator -- values are always visible as text
- DeepDivePanel and AssumptionTracker close on Escape key press
- Slide-out panels trap focus while open
- Section nav items are clickable divs -- ensure `role="button"` and `tabIndex={0}` with Enter/Space handlers
