## Summary

Phase 16.1 replaces a 4-agent, 6-section parallel One Pager pipeline with a single Claude Sonnet API call via `onePagerGenerator.js`. The new generator:

- Builds a system prompt from three curriculum files (role instruction + curriculum + writing guide + template)
- Sends the full DataPacket as the user message
- Parses structured output via `zodOutputFormat(OnePagerOutputSchema)` — 6 sections in one response
- Transforms the flat schema output to the backward-compatible 6-section array format expected by the PDF generator, gate check, and `useOnePager` hook
- Writes to `one-pager.json` (not `pipeline-output.json`)

The CC skill was simplified from 350 lines (11 steps with multi-agent orchestration) to 77 lines (4 steps: validate, run, review, optional quality check). The dispatch table entry was replaced with `mode: "single-call"` metadata. The pitchDeck and fullStory pipelines are completely untouched.

All code-verifiable must-haves pass. One live runtime test is flagged for human confirmation.
