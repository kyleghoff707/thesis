1. Read the current residual formulas from edgarFinancials.js `getDerivedFormula()` and the actual computation blocks:

**Current formulas (from getDerivedFormula):**
- `other_current_assets` = current_assets - cash - short_term_investments - accounts_receivable - inventory - prepaid_expenses
- `other_current_liabilities` = current_liabilities - accounts_payable - accrued_liabilities - short_term_debt - current_portion_lt_debt - operating_lease_current - finance_lease_current - deferred_revenue_current - taxes_payable
- `other_noncurrent_assets` = noncurrent_assets - property_plant_equipment - goodwill - intangible_assets - long_term_investments - deferred_tax_assets

**MS formulas (from RESEARCH.md Category F):**
- Other Current Assets = Total CA - Cash - ST Investments - Receivables - Inventory - Prepaid
- Other Non-Current Assets = Total NCA - PP&E - Goodwill - Intangibles - LT Investments - DTA - **ROU**
- Other Non-Current Liabilities = Total NCL - LT Debt - **LT Lease** - DTL - **Pension**
- Other Current Liabilities = Total CL - Payables&Accrued - CurrentDebt - **Provisions** - **DeferredLiabilities**

2. Identify gaps between engine and MS formulas:

For OtherNCA: Engine is missing ROU assets (`operating_lease_right_of_use_asset` or similar). This means the engine's OtherNCA is inflated by the ROU asset amount — producing a larger "Other" than MS.

For OtherNCL: Engine already includes operating_lease_noncurrent, finance_lease_noncurrent, deferred_tax_liabilities, pension_liabilities. But check if `deferred_revenue_noncurrent` is in the subtraction list (it should be, but MS formula doesn't show it — investigate whether MS nets it differently).

For OtherCA: Engine and MS formulas look aligned. Investigate why 44 DIFFs still exist — may be missing tax-related current assets or hedge derivatives.

For OtherCL: Engine already has 8 named items (the 95% gate). MS formula is different: subtracts Payables&Accrued (combined), CurrentDebt, Provisions, DeferredLiabilities. Our engine subtracts them separately. The gap may be in what "CurrentDebt" means (we subtract short_term_debt + current_portion_lt_debt separately, MS may combine differently).

3. Run analysis on specific companies to see the residual diff direction:

```bash
node -e "

['other_noncurrent_assets', 'other_noncurrent_liabilities', 'other_current_assets', 'other_current_liabilities'].forEach(field => {
  const diffs = [];
  data.companies.forEach(co => {
    co.results.filter(r => r.thesisField === field && r.status === 'DIFF').forEach(r => {
      diffs.push({ ticker: co.ticker, year: r.msYear, expected: r.expected, actual: r.actual });
    });
  });
  const engineHigher = diffs.filter(d => d.actual > d.expected).length;
  const msHigher = diffs.filter(d => d.expected > d.actual).length;
  console.log(field + ':', diffs.length, 'DIFFs | Engine higher:', engineHigher, '| MS higher:', msHigher);
  // Show top 3 examples
  diffs.slice(0,3).forEach(d => console.log('  ', d.ticker, d.year, 'MS:', d.expected, 'Engine:', d.actual, 'diff:', d.actual - d.expected));
});
"
```
