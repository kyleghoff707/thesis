  <action>
    **Root cause:** The current `accrued_combined_skip` handler checks if ANY year has separate accrued. If any year does, it compares ALL years. But the comparison is per-year, and some years may lack the separate accrued field while the company has it in other years. The 141 failures come from:
    1. Combined-only companies where some years have the separate field and others don't (per-year inconsistency)
    2. Companies where MS shows a different value for "Accrued Expenses, Current" than what our engine extracts (genuine methodology difference)

    **Fix the handler to per-year logic:**

    Replace the current `accrued_combined_skip` handler in `validation/scripts/lib/field-mapper.mjs`:

    ```javascript
    /**
     * Accrued liabilities: Skip comparison for year-level entries where MS has no
     * separate "Accrued Expenses, Current" field.
     *
     * MS uses two DataIDs:
     * - DataID 23004: "Accrued Expenses, Current" (separate — when XBRL has distinct tag)
     * - DataID 23166: "Payables and Accrued Expenses" (combined AP+Accrued — when XBRL
     *   only has AccountsPayableAndAccruedLiabilitiesCurrent)
     *
     * When only the combined tag exists, MS shows it under "Payables and Accrued Expenses"
     * and does NOT produce a separate accrued line. Comparing against a null or absent
     * accrued line is a false failure.
     *
     * Changed from v1 (all-or-nothing company-level check) to per-year check: skip only
     * years where the current year's data lacks the separate accrued field.
     *
     * @param {number} msValue - Raw MS value for "Accrued Expenses, Current" for THIS year
     * @param {object} allYearsData - All years' MS data { year: { field: val } }
     * @param {string} currentYear - The year being compared
     * @returns {number|'SKIP'} Original value or 'SKIP'
     */
    accrued_combined_skip(msValue, allYearsData, currentYear) {
      // If this specific year has no separate accrued field, skip
      const yearData = allYearsData[currentYear];
      if (!yearData || yearData['Accrued Expenses, Current'] == null) {
        return 'SKIP';
      }
      return msValue;
    }
    ```

    **Update comparator.mjs integration to pass the current year:**

    In `comparator.mjs`, the accrued handler call (around line 129-133) currently passes `msStmt` (all years). Update it to also pass the current `msYear`:

    ```javascript
    // Accrued liabilities: skip years where MS has no separate accrued line
    if (msField === 'Accrued Expenses, Current' && msValue != null && specialHandlers.accrued_combined_skip) {
      const adjusted = specialHandlers.accrued_combined_skip(msValue, msStmt, msYear);
      if (adjusted === 'SKIP') continue;
      msValue = adjusted;
    }
    ```

    This is a minimal change — adds `msYear` as the third argument. The `msYear` variable is already in scope (it's the loop variable from line 112).
