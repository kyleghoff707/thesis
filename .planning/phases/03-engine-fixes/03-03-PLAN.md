  **Residual "Other" Computation with Precondition Gate (ENGINE-02):**

  The residual "Other" fields (other_current_liabilities, other_noncurrent_liabilities, other_current_assets, other_noncurrent_assets, and cash flow "other" items) are computed by subtracting named items from totals. When named items have errors, the residual amplifies them.

  Enable the residual computation with a precondition gate:

  1. In `computeDerivedFields`, before the residual computation section (around line 1101 for BS, line 1257 for CF), add a coverage check function:

  ```javascript
  /**
   * Check if named items cover >= threshold of the total for a balance sheet category.
   * Used to gate residual "Other" computation — only compute when named items are accurate enough.
   */
  function namedItemCoverage(namedItems, total) {
    if (total == null || total === 0) return 0;
    const sum = namedItems.reduce((s, v) => s + Math.abs(v ?? 0), 0);
    return sum / Math.abs(total);
  }
  ```

  2. For **balance sheet residuals**, gate each one:

  ```javascript
  // Other Current Liabilities = Current Liabilities - (AP + ST Debt + Accrued Liabilities + ...)
  {
    const named = [bal.accounts_payable, bal.short_term_debt, bal.accrued_liabilities, bal.deferred_revenue_current, bal.current_portion_lt_debt];
    const coverage = namedItemCoverage(named, bal.current_liabilities);
    if (coverage >= 0.95 && bal.other_current_liabilities == null && bal.current_liabilities != null) {
      const namedSum = named.reduce((s, v) => s + (v ?? 0), 0);
      bal.other_current_liabilities = bal.current_liabilities - namedSum;
    }
  }
  ```

  Apply similar pattern for:
  - `other_noncurrent_liabilities` = noncurrent_liabilities - (long_term_debt + deferred_tax_liabilities + ...)
  - `other_current_assets` = current_assets - (cash + short_term_investments + accounts_receivable + inventory + ...)
  - `other_noncurrent_assets` = noncurrent_assets - (property_plant_equipment + goodwill + intangible_assets + ...)

  3. For **cash flow residuals** (line 1257), apply the same gating pattern. Check coverage of named CF items against total operating/investing/financing cash flow before computing residuals.

  4. The 95% threshold means: if named items account for >= 95% of the total, the residual is small enough that any upstream error won't blow it up. Per ENGINE-02 requirement, this gate MUST be per-company-year, not global.
