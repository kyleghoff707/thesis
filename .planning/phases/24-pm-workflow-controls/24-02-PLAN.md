    **Button state determination (pure function, export via _testExports):**
    ```javascript
    function getButtonState(report, stageAvailability, generating) {
      if (generating) return { label: 'Generating...', action: 'disabled', stage: null, style: 'disabled' };

      const approvals = report?.stageApprovals || {};
      const avail = stageAvailability || {};

      // Walk through stages in order
      if (!avail.onePager) return { label: 'Generate One Pager', action: 'generate', stage: 'one-pager', style: 'primary' };
      if (approvals.onePager !== 'approved') return { label: 'View One Pager', action: 'view', stage: 'one-pager', route: `/reports/${ticker}/one-pager`, style: 'ghost' };

      if (!avail.pitchDeck) return { label: 'Generate Pitch Deck', action: 'generate', stage: 'pitch-deck', style: 'primary' };
      if (approvals.pitchDeck !== 'approved') return { label: 'View Pitch Deck', action: 'view', stage: 'pitch-deck', route: `/reports/${ticker}/pitch-deck`, style: 'ghost' };

      if (!avail.fullStory) return { label: 'Generate Full Story', action: 'generate', stage: 'full-story', style: 'primary' };
      // FS exists (generated or approved)
      return { label: 'View Full Story', action: 'view', stage: 'full-story', route: `/reports/${ticker}/full-story`, style: 'ghost' };
    }
    ```

    Note: `ticker` is accessed from the component's props via closure — the pure function needs ticker for route building, so pass it as a parameter or build routes in the component.

    **Render:**
    - Call `getButtonState(report, stageAvailability, generating)` to get current state
    - If action === 'disabled': render disabled button with 12px Spinner to left of text. Style: `background: C.badge, color: C.badgeText, border: 'none', cursor: 'default', opacity: 0.7`
    - If action === 'generate': render primary button that opens ConfirmGenerateDialog. Style: `background: C.accent, color: '#fff', padding: '8px 20px', borderRadius: 6, fontSize: 13, fontWeight: 600, cursor: 'pointer'`. Hover: set background to C.accentHover via onMouseEnter/onMouseLeave state.

    - When showDialog is true, render `<ConfirmGenerateDialog ticker={ticker} stage={state.stage} onConfirm={() => { setShowDialog(false); onGenerate(state.stage); }} onCancel={() => setShowDialog(false)} />`
