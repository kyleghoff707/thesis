Create three new Python modules in scripts/pdf/:

**1. report_data_reader.py** -- Unified JSON reader class:
- Class `ReportData(ticker, stage)` where stage is 'one-pager' | 'pitch-deck' | 'full-story'
- `__init__` loads the appropriate JSON file: one-pager.json, pipeline-output.json, or full-story-api.json from `.thes1s/reports/{ticker}/`
- Also loads data-packet.json into self.data_packet
- Builds self.sections dict keyed by section key: `{s['key']: s for s in report.get('sections', [])}`
- Methods:
  - `get_company_name()` -- from report.companyName or data_packet.companyInfo.name
  - `get_ticker()` -- self.ticker
  - `get_overall_verdict()` -- One Pager: report['overallVerdict']; PD/FS: sections['overall_verdict'].data.overallVerdict
  - `get_section_keys()` -- One Pager: report['sectionKeys']; PD/FS: [s['key'] for s in sections]
  - `get_sections_ordered()` -- returns list of section dicts in order
  - `get_financial_years(n=5)` -- data_packet.financials.years[-n:]
  - `get_debate_outputs()` -- report.debateOutputs (Full Story only, else {})
  - `get_stage_label()` -- returns 'One Pager', 'Pitch Deck', or 'Full Story'
- Handle missing files with FileNotFoundError and clear error message
- Filter out reader sections (skip any section where 'reader' in key) for backward compat with old CC pipeline output

**2. section_renderers.py** -- Pure helper functions (no format-specific code):
- `get_narrative(section)` -- returns best available text: narrative if >100 chars and not placeholder, else verdictRationale + summary joined
- `get_tables(section)` -- returns list of table dicts, filtering non-dict entries (polymorphism guard: `isinstance(t, dict) and t.get('headers')`)
- `get_red_flags(section)` -- normalize to string list (str passthrough, dict extracts flag/detail key)
- `get_citations(section)` -- normalize to list of {ref, text, source} dicts (handles str/dict/int polymorphism)
- `get_checklist_items(section)` -- returns data.items or data.checklistItems or []
- `get_verdict_color(verdict)` -- maps PASS/FAIL/PARTIAL/BUY/SELL/HOLD to color tuples for both PDF and Word
- `truncate(text, max_len=500)` -- truncate with ellipsis for table cells

**3. thes1s_pdf.py** -- Shared Thes1s-branded PDF base class:
- `class Thes1sPDF(ReportPDF)` that extracts ALL shared code from OnePagerPDF and PitchDeckPDF
- Import: `from pdf_template_toolkit import ReportPDF`
- `__init__(self, title, subtitle='', stage_label='Report')` -- sets Thes1s palette (identical between both existing classes):
  - color_primary = (15, 118, 110), color_secondary = (30, 41, 59), color_text = (30, 41, 59)
  - color_muted = (100, 116, 139), color_light_muted = (148, 163, 184), color_accent = (15, 118, 110)
  - color_table_header = (15, 118, 110), color_table_alt_row = (240, 253, 250)
  - Extended palette: teal_500, teal_400, teal_300, teal_100, teal_50, slate_800..100, red_500/400, amber_500/400, green_500/400, blue_500/400
  - self.stage_label = stage_label
- `draw_logo(self, x, y, size=22)` -- copy from OnePagerPDF (identical in both)
- `footer(self)` -- uses self.stage_label: `f'Thes1s  |  {self.stage_label}  |  Page {self.page_no() - 1}'`
- `add_title_page(self, info_lines=None, disclaimer=None)` -- copy from OnePagerPDF (identical in both)
- `add_smart_section_header(self, title, min_space=100)` -- copy from OnePagerPDF
- `draw_verdict_scorecard(self, title, sections)` -- copy from OnePagerPDF
- `draw_metric_gauges(self, title, gauges)` -- copy from OnePagerPDF
- `draw_bar_chart(self, title, labels, values, colors, unit='', max_val=None, subtitle='')` -- copy from PitchDeckPDF (superset of base class version)
- `draw_comparison_bar_chart(self, title, labels, series, series_names, series_colors, unit='', max_val=None)` -- copy from PitchDeckPDF
- `draw_price_range_chart(self, title, methods, current_price)` -- copy from OnePagerPDF
- `draw_pn_bar_chart(self, title, labels, values, colors_pos, colors_neg, unit='', subtitle='')` -- copy from OnePagerPDF
