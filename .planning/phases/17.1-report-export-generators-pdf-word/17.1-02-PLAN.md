**Page structure (10-section layout):**

1. **Title page** -- Thes1sPDF.add_title_page() with:
   - Company name, ticker, date from data
   - Overall verdict from `data.sections.get('overall_verdict', {})` -- extract from `section.get('data', {}).get('overallVerdict', 'N/A')` (NOT top-level)
   - Stage: "Pitch Deck -- Investment Analysis"

   - Verdict badge, key strengths, key concerns, next steps
   - Extract from overall_verdict section's data dict: data.get('keyStrengths', []), data.get('keyConcerns', []), data.get('nextSteps', [])
   - Verdict scorecard: each section's verdict in a summary card

3. **10 Section pages** -- For each section in data.get_sections_ordered():
   - add_smart_section_header with `f"{section.get('sectionNumber', i+1)}. {section.get('title', section['key'])}"`
   - **Narrative block:** render get_narrative(section) using add_body_text. Split long narratives into paragraphs on double-newline.
   - **Tables:** For each table from get_tables(section), render with pdf.add_table(table['headers'], table.get('rows', [])). Add table title with add_section_header(title, level=2).
   - **Red flags:** render get_red_flags(section) as bulleted list with red accent color
   - **Per-section citations:** render get_citations(section) as small-font numbered list at end of section
   - Skip sections where key contains 'reader' (backward compat filter)

4. **Financial charts from DataPacket** (after section pages):
   - Revenue + EPS bar chart: financials.income[year].revenues and .basic_eps for last 5 years
   - FCF trajectory: fcf.yearly or fcf.series for last 5 years
   - Rule One gauges: ruleOneScore.moat, .management, .composite
   - Buy price range chart: if valuation_summary section has buy price data, render draw_price_range_chart with MOS, PBT, TenCap, EB methods vs current price
   - Guard all charts with null/missing data checks -- skip gracefully

5. **Back page** -- Citations appendix (all unique citations across all sections, deduplicated by source)

**Critical anti-patterns to avoid:**
- Do NOT use section key `simple_predictable` -- the correct key is `simple_and_predictable`
- Do NOT read `rpt['overallVerdict']` from top level -- it's in `sections['overall_verdict'].data`
- Do NOT read `rpt.get('synthesisNarrative')` -- construct from overall_verdict narrative
- Do NOT hardcode any ticker name or financial data
- Use isinstance() checks on all table/citation/redFlag data before accessing dict keys

- `python3 scripts/pdf/generate_full_story_pdf.py MNST` (positional arg via sys.argv[1])
- Outputs to `.thes1s/reports/{TICKER}/full-story.pdf`

**Main function: `def generate_full_story_pdf(ticker):`**

**Page structure:**

1. **Title page** -- Thes1sPDF(title, subtitle, stage_label='Full Story').add_title_page() with:
   - Company name, ticker, date
   - Stage: "Full Story -- Investment Thesis"
   - No top-level overallVerdict for Full Story -- the judge verdict serves this role

2. **6 Section pages** -- iterate data.get_sections_ordered():

   For **standard sections** (event_analysis, valuation_confirmation):
   - add_smart_section_header with section title
   - Render narrative via get_narrative(section) using add_body_text
   - Render tables via get_tables(section)
   - Render red flags via get_red_flags(section)
   - Render per-section citations

   For **checklist sections** (meaning_checklist, moat_checklist, management_checklist):
   - add_smart_section_header with section title
   - Render narrative summary first (overview of the checklist)
   - Then render checklist items as a table:
     - Headers: ['#', 'Item', 'Verdict', 'Confidence']
     - Rows from get_checklist_items(section): [item.number, item.item, item.verdict, item.confidence]
     - Color-code verdict cells: PASS=green, FAIL=red, PARTIAL=amber (use set_fill_color before cell if possible, or just text)
   - After the table, render evidence for each item that has substantive evidence (>50 chars):
     - add_section_header(f"Item {item['number']}: {item['item'][:60]}", level=3)
     - add_body_text(item['evidence'])
   - Tally at end of checklist: "Score: X PASS / Y PARTIAL / Z FAIL out of N items"

   For **inversion_rebuttal section**:
   - Render section narrative first
   - Then render the 4-step debate from data.get_debate_outputs():

3. **Adversarial Debate rendering** (after inversion_rebuttal narrative):

   **Bull Thesis** (debate_outputs['bull']['content']):
   - add_section_header('Bull Thesis', level=2)
   - add_body_text(content.get('overallThesis', ''))
   - For each point in content.get('thesisPoints', []):
     - add_bullet(f"{point.get('point', '')} -- Evidence: {point.get('evidence', '')[:200]}")

   **Bear Inversion** (debate_outputs['bear']['content']):
   - add_section_header('Bear Inversion', level=2)
   - add_body_text(content.get('overallBearCase', ''))
   - For each inv in content.get('inversions', []):
     - severity = inv.get('severity', 'MEDIUM')
     - add_bullet(f"[{severity}] {inv.get('counterArgument', '')[:300]}")

   **Bull Rebuttal** (debate_outputs['bull_rebuttal']['content']):
   - add_section_header('Bull Rebuttal', level=2)
   - For each reb in content.get('rebuttals', []):
     - strength = reb.get('rebuttalStrength', 'N/A')
     - add_bullet(f"[{strength}] {reb.get('rebuttal', '')[:300]}")

   **Judge Verdict** (debate_outputs['judge']['content']):
   - add_section_header('Judge Verdict', level=2)
   - verdict = content.get('overallVerdict', {})
   - add_body_text(f"Direction: {verdict.get('direction', 'N/A')}")
   - add_body_text(f"Unresolved Risks: {verdict.get('unresolvedCount', 0)}")
   - add_body_text(verdict.get('summary', ''))
   - Exchanges table: headers ['Topic', 'Bull', 'Bear', 'Verdict'], rows from content.get('exchanges', [])

4. **Financial charts from DataPacket** (same pattern as Pitch Deck but shorter -- focus on key metrics):
   - Rule One gauges
   - Buy price range chart (if data available from valuation_confirmation section)

**All debate/checklist data access must use .get() with fallback defaults.** The debate structure has nested dicts -- guard every level.

**Output:** `.thes1s/reports/{ticker}/full-story.pdf`
