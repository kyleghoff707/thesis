Functions:
- `setup_thes1s_styles(doc)` -- Configure the Document's default styles:
  - Normal style: font.name = 'Arial', font.size = Pt(10), font.color.rgb = SLATE_800
  - Heading 1: font.name = 'Arial', font.size = Pt(16), font.bold = True, font.color.rgb = TEAL_500
  - Heading 2: font.name = 'Arial', font.size = Pt(13), font.bold = True, font.color.rgb = SLATE_800
  - Heading 3: font.name = 'Arial', font.size = Pt(11), font.bold = True, font.color.rgb = TEAL_500
  - Set narrow margins (2cm all sides) via doc.sections[0].left_margin etc.

- `add_title_page(doc, title, subtitle, info_lines)` -- Add a title page:
  - Centered title paragraph with Pt(28), bold, TEAL_500 color
  - Subtitle paragraph with Pt(14), SLATE_800
  - Info lines as Pt(10) paragraphs (ticker, date, verdict, etc.)
  - Page break after

- `add_styled_table(doc, headers, rows)` -- Add a Thes1s-branded table:
  - Table Grid style
  - Header row: teal background (TEAL_500_HEX), white bold text Pt(9)
  - Data rows: Pt(9) font, alternating row shading (even rows get TEAL_50_HEX)
  - Cell shading via parse_xml(f'<w:shd {nsdecls("w")} w:fill="{hex}"/>')
  - Guard: if not headers or not rows, return None

- `add_verdict_badge(doc, verdict)` -- Add a verdict paragraph:
  - Bold text with color: PASS=GREEN_500, FAIL=RED_500, PARTIAL/HOLD=AMBER_500, BUY=GREEN_500
  - Format: "Verdict: {verdict}" in Pt(12) bold

- `add_section_narrative(doc, narrative)` -- Render narrative text:
  - Split on double-newline for paragraphs
  - Each paragraph as Normal style
  - Handle None/empty gracefully

- `add_citations_section(doc, citations)` -- Render citations list:
  - Heading 3: "Citations"
  - Each citation as small Pt(8) paragraph: "[{i}] {ref} -- {source}"

**2. scripts/pdf/generate_full_story_docx.py** -- Full Story Word doc:

CLI: `python3 scripts/pdf/generate_full_story_docx.py MNST` (sys.argv[1])
Output: `.thes1s/reports/{ticker}/full-story.docx`

Structure:
- Load data: `ReportData(ticker, 'full-story')`
- Create Document, setup_thes1s_styles(doc)
- Title page: add_title_page(doc, company_name, 'Full Story -- Investment Thesis', [ticker, date])
- For each section in data.get_sections_ordered():
  - doc.add_heading(section.get('title', section['key']), level=1)
  - add_section_narrative(doc, get_narrative(section))

  - **Checklist sections** (key contains 'checklist'):
    - items = get_checklist_items(section)
    - If items: add_styled_table(doc, ['#', 'Item', 'Verdict', 'Confidence'], [[str(i.get('number','')), i.get('item',''), i.get('verdict',''), i.get('confidence','')] for i in items])
    - Tally: count PASS/FAIL/PARTIAL, add paragraph: "Score: X PASS / Y PARTIAL / Z FAIL out of N"
    - Evidence: for items with evidence >50 chars, add Heading 3 with item name + Normal paragraph with evidence text

  - **Standard sections** (event_analysis, valuation_confirmation):
    - Tables from get_tables(section) via add_styled_table
    - Red flags as bullet list
    - Citations via add_citations_section

  - **Inversion & rebuttal section**:
    - Render section narrative first
    - Then render debate from data.get_debate_outputs():
      - doc.add_heading('Bull Thesis', level=2)
      - Render overallThesis + each thesisPoint as bullet
      - doc.add_heading('Bear Inversion', level=2)
      - Render overallBearCase + each inversion as "[SEVERITY] counterArgument" bullet
      - doc.add_heading('Bull Rebuttal', level=2)
      - Each rebuttal as "[strength] rebuttal" bullet
      - doc.add_heading('Judge Verdict', level=2)
      - Direction, unresolved count, summary as paragraphs
      - Exchanges as styled table: ['Topic', 'Bull', 'Bear', 'Verdict']

  - Page break between sections: doc.add_page_break()
- Save to `.thes1s/reports/{ticker}/full-story.docx`

**Guard all nested dict access with .get() defaults.** Debate content can have missing keys.
