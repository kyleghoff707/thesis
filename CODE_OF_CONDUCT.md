# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html), version 2.1, as its code of conduct. The full text — pledge, standards, enforcement guidelines, and attribution — is available at the link above.

In short: be respectful, be welcoming, focus on what's best for the community. Disagreement is fine; personal attacks are not.

## Scope

This code applies to all project spaces — GitHub issues, pull requests, discussions, the project's website, and any other forum officially associated with Thesis — and to participants representing the project in public.

## Reporting

Concerns about behavior in this community should be reported to **kyle@thesis-investing.com**. Reports are reviewed promptly and confidentially. The project maintainer is obligated to respect the privacy and security of anyone reporting an incident.

## Enforcement

The project maintainer may issue warnings, remove contributions, or ban participants for behavior that violates this code. Decisions are made at the maintainer's discretion, guided by the Contributor Covenant enforcement guidelines linked above.
