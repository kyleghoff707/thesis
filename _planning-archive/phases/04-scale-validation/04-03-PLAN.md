Create `validation/scripts/validate-sp500-identities.mjs` -- an orchestrator that runs the existing `validateCompany()` function for all 503 S&P 500 companies and produces a JSON + console report.

**Structure (following compare-sp500-fmp.mjs pattern exactly):**

1. **Browser polyfills**: Copy the `globalThis.localStorage` mock from compare-sp500-fmp.mjs.

2. **SEC fetch interceptor**: Copy the full SEC fetch interceptor from compare-sp500-fmp.mjs (URL rewriting, disk cache in `validation/cache/edgar-sp500/`, 100ms rate limit, User-Agent header). Reuse the same EDGAR cache directory so cache hits from Plan 02's comparison run carry over.

3. **Auto-build engine bundle**: Check for `bundled-engines.mjs`, auto-build if missing via `execSync('node validation/scripts/bundle.mjs')`.

4. **Import dependencies**:
   ```javascript
   const { fetchEdgarStatements, validateCompany } = await import('./bundled-engines.mjs');
   ```

5. **Load ticker list**: Read `validation/data/sp500-tickers.json`. If missing, print error and exit 1.

6. **CLI args**: `--ticker AAPL,MSFT` for single/multi ticker mode.

7. **Main loop** -- For each ticker:
   - Clear localStorage between tickers.
   - Fetch engine data: `await fetchEdgarStatements(ticker, { version: 'restated' })`.
   - If null, record as `{ ticker, status: 'ENGINE_ERROR', checks: {} }` and continue.
   - Run validation: `await validateCompany(ticker, engineData, { skipFrames: true })`. Set `skipFrames: true` because Frames API validation is expensive at 503 companies and not relevant to identity checks.
   - Extract `identityChecks` from the validation result.
   - Compute per-company pass rate: count checks with `status === 'pass'` vs total non-skip checks across all years.
   - Progress to stderr: `AAPL     [1/503]  95.0% pass  (38/40 checks)`.
   - Rate limit: `await sleep(100)` between tickers.

8. **Console report** (write to stdout):
   ```
   S&P 500 ACCOUNTING IDENTITY CHECK REPORT
   ==========================================
   Companies: 503 | Processed: X | Errors: Y

   OVERALL PASS RATE
     Pass: X / Y checks (XX.X%)

   PER-CHECK PASS RATES
     Check Name                        Pass%    Fail    Skip
     Assets = Liabilities + Equity     98.2%    12      45
     Gross Profit = Revenue - COGS     99.1%    5       20
     ...

   COMPANIES WITH MOST FAILURES (top 10)
     Ticker   Pass%   Fail Count   Top Failing Check
     BRK-B    72.0%   14           Assets = L + E
     ...
   ```

9. **JSON report** -- Write to `validation/reports/sp500-identity-checks.json`:
   ```javascript
   {
     timestamp: ISO,
     summary: {
       totalCompanies: N,
       processed: N,
       errors: N,
       overallPassRate: XX.X,
       perCheckPassRates: { "Assets = Liabilities + Equity": { pass, fail, skip, rate }, ... },
     },
     companies: [
       { ticker, status, passRate, totalChecks, passCount, failCount, skipCount,
         failingChecks: [{ year, name, detail, expected, actual, pct }] },
     ],
   }
   ```

10. **Exit code**: 0 if overall pass rate > 90%, 1 otherwise.

**Key implementation details:**
- The `validateCompany` function's `identityChecks` is keyed by year: `{ "2024": [{ name, status, detail, expected?, actual?, pct? }], "2023": [...] }`.
- Each check has `status: 'pass' | 'fail' | 'skip'`. Skip means insufficient data for the check.
- Aggregate across ALL years for the per-company pass rate.
- For the per-check breakdown, iterate all companies and years, group by check name.
