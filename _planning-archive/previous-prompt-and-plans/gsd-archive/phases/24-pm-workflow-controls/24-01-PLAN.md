    **Create src/hooks/useCheckpoint.js:**

    ```javascript
    import { useState, useEffect, useCallback } from 'react';
    import { v4 as uuidv4 } from 'uuid';
    import { idbGet, idbSet, idbDelete } from '../engines/cacheStore';
    ```

    Export: `export function useCheckpoint(ticker, checkpointNum)`

    Returns: `{ comments, dataGapResponses, attachments, loading, error, saveComment, removeComment, addAttachment, removeAttachment, saveDataGapResponse, submitCheckpoint }`

    State:
    - `comments` — object keyed by sectionKey: `{ text, attachments: [{id, name, type, size}], createdAt }`
    - `dataGapResponses` — object keyed by gap ID: `{ response: 'url'|'file'|'text', value, attachments }`
    - `attachments` — Map of attachment IDs to metadata (for display)
    - `loading` — boolean
    - `error` — string or null

    On mount (useEffect with [ticker, checkpointNum]):
    1. If !ticker || checkpointNum == null, return early
    2. Fetch `GET /api/thes1s/reports/${ticker}/checkpoint/${checkpointNum}` for server-side state
    3. Also check IndexedDB for any locally-stored comments/attachments (key: `checkpoint:${ticker}:${checkpointNum}`)
    4. Merge server + local state (local takes precedence for in-progress edits)
    5. Set loading false

    Functions:
    - `saveComment(sectionKey, text)` — Update comments[sectionKey].text, persist to IndexedDB immediately (fire-and-forget via `idbSet('checkpoint-attachments', ...)`)
    - `addAttachment(sectionKey, file)` — Validate file.size <= 10 * 1024 * 1024 (10MB). If over, set error "File exceeds 10MB limit". Otherwise: `const id = uuidv4()`, read file as ArrayBuffer via `file.arrayBuffer()`, store in IndexedDB under `checkpoint-attachments` store with key `att:${id}`, value `{ name: file.name, type: file.type, size: file.size, ticker, checkpointPhase: checkpointNum, sectionKey, buffer }`, TTL 10 years (10 * 365 * 24 * 60 * 60 * 1000). Add attachment ref to comments[sectionKey].attachments array.
    - `removeAttachment(sectionKey, attachmentId)` — Remove from IndexedDB via `idbDelete('checkpoint-attachments', 'att:' + attachmentId)`. Remove from comments[sectionKey].attachments.
    - `removeComment(sectionKey)` — Clear comments[sectionKey]
    - `saveDataGapResponse(gapId, responseType, value, attachmentRefs)` — Update dataGapResponses[gapId]
    - `submitCheckpoint(action)` — action is 'continue' or 'rerun'. Build full feedback object: `{ checkpointPhase: checkpointNum, comments, dataGapResponses, action, timestamp: new Date().toISOString() }`. For attachments, read ArrayBuffer from IndexedDB, convert to base64 string, include in POST body. POST to `/api/thes1s/reports/${ticker}/checkpoint` with JSON body. Return response.

    Export: `export function useGeneratePipeline(ticker)`

    Returns: `{ triggerGeneration, generating, generationError }`

    State:
    - `generating` — boolean (true while POST is in-flight)
    - `generationError` — string or null

    Function `triggerGeneration(stage)`:
    - stage: 'one-pager' | 'pitch-deck' | 'full-story'
    - Set generating = true, generationError = null
    - POST to `/api/thes1s/generate/${encodeURIComponent(ticker)}/${stage}` with empty body
    - If response status 202: generation started. Set generating = false, return { started: true }
    - If response status 501: not implemented yet. Set generationError to response message. Set generating = false, return { started: false, notImplemented: true }
    - If any other status or fetch error: set generationError to error message, set generating = false, return { started: false, error: true }
    - Polling is NOT handled here — the existing usePitchDeck/useOnePager/useFullStory hooks already poll progress. The caller starts polling after triggerGeneration returns { started: true }.
