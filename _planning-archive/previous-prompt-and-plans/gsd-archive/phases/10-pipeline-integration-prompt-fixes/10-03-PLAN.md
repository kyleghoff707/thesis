  <action>
    Create `scripts/run-pipeline.js` -- a Node.js CLI script that:

    1. Takes a ticker as the first CLI argument (`process.argv[2]`), defaults to `'SFM'`
    2. Imports `assembleDataPacket` from `../src/engines/dataExport.js`
    3. Imports `runPipeline` from `../src/engines/pipelineManager.js`
    4. Imports `formatBudgetReport` from `../src/engines/contextBudget.js`
    5. Loads dotenv from `.env.local` (same pattern as aiResearch.js)
    6. Assembles the DataPacket via `assembleDataPacket(ticker)`
    7. Calls `runPipeline('pitchDeck', dataPacket, { onWaveComplete })` where `onWaveComplete` logs wave number, section count, budget snapshot, and cache stats to console
    8. After completion, logs:
       - Total sections produced (count)
       - Section keys and titles
       - Error count and details (if any)
       - Budget report via `formatBudgetReport(result.budget)`
       - Cache stats summary
       - For each section: key, title, status, confidence, citation count, redFlags count, searchesPerformed count
    9. Writes the full result (sections array + budget + errors) to `.thes1s/reports/{TICKER}/pipeline-output.json`
    10. Exits with code 0 if all 10 sections + synthesis produced, code 1 otherwise

    The script must handle errors gracefully -- if assembleDataPacket fails, log the error and exit. If runPipeline partially fails, still write whatever output was produced.

    Use ESM imports (the project uses `"type": "module"` in package.json).

    **Do NOT run the script.** This is preparation for the PM checkpoint. The PM will run it.
  </action>
