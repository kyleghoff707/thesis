## Interaction Contract

### Gate Logic

| Transition | Condition | Source |
|------------|-----------|--------|
| OP always accessible | None (first stage) | D-09 |
| PD requires OP approval | `stageApprovals.onePager === 'approved'` | D-09, PitchDeck.jsx line 413 |
| FS requires PD approval | `stageApprovals.pitchDeck === 'approved'` | D-09, FullStory.jsx gate check |

### Pill Click Behavior

| Pill State | Click Action |
|------------|-------------|
| Approved | Navigate to `/research/:id/{stage-key}` |
| Generated (not approved) | Navigate to `/research/:id/{stage-key}` |
| Pending (not generated) | No action (pill is non-interactive, no cursor change) |
| Locked (gated) | No navigation. Show browser `title` tooltip with gate message. cursor: not-allowed. |

Source: D-10 (locked pill does NOT navigate), D-02 (tooltip on locked)

### Tooltip Text (reuse from StageNavBar)

| Locked Stage | Tooltip |
|-------------|---------|
| Pitch Deck (OP not approved) | "Approve One Pager to unlock Pitch Deck" |
| Full Story (PD not approved) | "Approve Pitch Deck to unlock Full Story" |

Source: StageNavBar.jsx GATE_TOOLTIPS constant

### Stage Status Detection

| Status | Condition | Source |
|--------|-----------|--------|
| Approved | `stageApprovals[stage] === 'approved'` | D-04 |
| Generated | Report JSON exists on disk (from `/api/thes1s/reports` response) | D-04 |
| Rejected | Treated as "generated" (report exists, not approved) | D-04 |
| Pending | Stage report not generated | D-04 |

## API Contract

The `/api/thes1s/reports` endpoint currently returns `{ tickers: string[] }`. Phase 22 needs per-ticker stage availability. Two options (Claude's discretion per D-discretion):

**Option A (recommended):** Enhance API to return `{ tickers: [{ ticker, stages: { onePager: bool, pitchDeck: bool, fullStory: bool } }] }`. This avoids N+1 client requests.

**Option B:** Client-side: for each ticker, check if report data contains `onePager`/`pitchDeck`/`fullStory` keys after loading from IndexedDB. Simpler but requires loading all report data upfront.

The planner should choose based on implementation complexity. Both satisfy NAV-02 and NAV-04.
