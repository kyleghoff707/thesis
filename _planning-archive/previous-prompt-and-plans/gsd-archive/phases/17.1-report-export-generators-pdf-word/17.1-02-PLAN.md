    3. **Data**: `data = ReportData(ticker, 'pitch-deck')`

    c. **Per-section rendering** -- iterate over `data.get_section_keys()`:
       For each section:
       - `pdf.add_page()` for major sections (start each on new page)
       - Section header with number and title
       - Narrative text (via `get_narrative()`)
       - Tables (via `get_tables()`) -- render using `pdf.add_table(headers, rows)`
       - Red flags (via `get_red_flags()`) -- bullet list with red emphasis

       **Section-specific visuals (where data supports it):**
       - `radar`: Summary metrics table only (narrative-heavy)
       - `simple_and_predictable`: Revenue trend chart from DataPacket if available
       - `market_position`: Comparison bar chart if section has competitor data in tables
       - `barriers_and_moats`: Narrative-focused (moats are qualitative)
       - `fcf`: FCF bar chart from DataPacket (`cashFlow.free_cash_flow`), Owner Earnings if available
       - `management`: Score gauges if data.management has scores
       - `balance_sheet`: Debt/equity comparison bar chart from DataPacket if available
       - `pest_risks`: Narrative-only (risks are qualitative)
       - `valuation_summary`: **Key visual section** -- price range chart via `pdf.draw_price_range_chart()` using buy prices from `data.get_buy_prices()`. Also FGR derivation table if in section data.
       - `overall_verdict`: Verdict badge, key strengths/concerns as bullets, next steps

    d. **Citations page**: Collect all citations across all sections, render as numbered list at the end.

    e. **Output**: Save to `.thes1s/reports/{ticker}/pitch-deck.pdf`

    - No hardcoded SFM-specific data
    - Uses generic section rendering with strategic chart injection where data exists

    **Part B: CREATE `scripts/pdf/generate_full_story_pdf.py`**

    Entirely new. This is the most complex generator due to checklists and debate.

    1. **CLI**: `python3 scripts/pdf/generate_full_story_pdf.py MNST`
    2. **Imports**: Same as Pitch Deck plus debate/checklist helpers
    3. **Data**: `data = ReportData(ticker, 'full-story')`

    **Page structure:**

    a. **Title page**: `pdf.title_page(ticker, company, 'Full Story', 'Investment Thesis Deep Dive', verdict='')`
       Note: Full Story may not have a single overall verdict -- the debate IS the verdict.

    b. **Section 1 -- Event Analysis** (`event_analysis`):
       - Narrative rendering
       - Tables if present (catalyst events, timeline)
       - Red flags

    c. **Sections 2-4 -- Checklists** (`meaning_checklist`, `moat_checklist`, `management_checklist`):
       Each checklist section gets:
       - **Checklist summary visual**: A colored summary bar showing PASS/FAIL/PARTIAL counts using `pdf.draw_metric_gauges()` with items=[("PASS", pass_count, total, ""), ("FAIL", fail_count, total, ""), ("PARTIAL", partial_count, total, "")]
       - **Checklist table**: Headers = ['#', 'Item', 'Verdict', 'Confidence'], rows from `get_checklist_items()`. Use colored verdict badges in the Verdict column (green for PASS, red for FAIL, amber for PARTIAL).
       - **Evidence detail**: For each item with substantial evidence (>100 chars), render as sub-section with header "Item N: {item_name}" and body text = evidence
       - **Narrative** at top if present

    d. **Section 5 -- Valuation Confirmation** (`valuation_confirmation`):
       - Narrative
       - **Price Range Chart**: If buy prices available from `data.get_buy_prices()`, draw price range chart
       - Tables (sensitivity tables if present)

    e. **Section 6 -- Inversion & Rebuttal** (`inversion_rebuttal`):
       - Section narrative (if exists in the section itself)
       - **Adversarial Debate rendering from `data.get_debate_outputs()`:**

         **Bull Thesis**: Header + overallThesis text + thesisPoints as numbered bullets
         **Bear Inversion**: Header + overallBearCase text + inversions as bullets with [SEVERITY] prefix and color (HIGH=red, MEDIUM=amber, LOW=green)
         **Bull Rebuttal**: Header + rebuttals as bullets with [strength] prefix
         **Judge Verdict**: 
           - Direction badge (colored: BULL=green, BEAR=red, MIXED=amber)
           - Unresolved risk count
           - Summary text
           - **Exchange Table**: Headers = ['Topic', 'Bull', 'Bear', 'Verdict'], rows from exchanges. Color-code verdict column.

    f. **Citations page**: Collect all citations.

    g. **Output**: Save to `.thes1s/reports/{ticker}/full-story.pdf`

    **Visual design philosophy for Full Story:**
    - Checklist verdict distributions (visual -- pass/fail/partial counts)
    - Checklist tables with color-coded verdict cells
    - Price range chart for valuation confirmation
    - Debate exchange table with verdict colors
    - Debate direction badge (visual verdict indicator)
    - Evidence text as readable body text (NOT visual -- text is appropriate here)

    Both generators must handle missing/empty data gracefully (skip charts if DataPacket data is missing, skip sections if they don't exist in the pipeline output).
