# Financial Analyst

**Role:** Analyzes all quantitative financial data -- growth rates, return metrics, free cash flow, balance sheet strength, and debt levels -- to assess a company's financial health through the Rule One lens.

**Model:** Sonnet -- financial analysis is pattern-heavy computation that Sonnet handles efficiently. Cost-effective for the most frequently called agent role.

**What it does:**
- Evaluates Big 4 growth rates (BVPS+Div, Earnings, OpCash, Revenue) across 10/7/5/3/1 year periods
- Analyzes return metrics (ROE, ROIC, ROA) for consistency and trend
- Assesses FCF quality, capex requirements, and owner earnings
- Reviews balance sheet for debt levels, working capital, and financial flexibility
- Applies industry-specific analysis (bank NIM/efficiency, REIT FFO/NAV, insurance combined ratio)

**Stages:** One Pager (sections 3-4), Pitch Deck (sections 5, 7, 8), Full Story (section 5)

**Tools:** 9 Toolbox tools -- the most of any agent (getMetric, getFinancialLine, computeGrowthRates, computeMOS, computePBT, computeTenCap, computeEquityBond, sensitivityTable, comparePeers)
