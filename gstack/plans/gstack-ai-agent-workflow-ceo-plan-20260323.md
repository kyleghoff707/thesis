## Vision

### 10x Check — What Makes Hedge Funds Say "Shut Up and Take My Money"

1. **Living Thesis Intelligence** — Every analyzed company becomes a living node. Quarterly earnings auto-trigger re-analysis of affected sections. Your research stays current without 40 hours of re-work.

2. **Management Promise Tracker** — Primary Source Reader extracts forward-looking statements from earnings calls, tags them with quarter/year, and compares promises to actual results. Produces a management credibility score. No existing tool does this.

3. **Cross-Company Intelligence** — Research compounds. Analyzing COST automatically surfaces findings from your WMT analysis. Your 50th analysis is richer than your 1st because of accumulated context.

4. **Conviction Scoring** — Weighted thesis probability that updates as evidence accumulates. Not binary PASS/FAIL but a Bayesian posterior.

5. **Presentation-Ready PDF** — Branded, professional PDFs with Thes1s aesthetic. Charts, footnoted citations, executive summary. The product demo that closes deals.

### Platonic Ideal

Type "COST" and get a report that reads like a Berkshire Hathaway internal analysis memo. Every claim traces to a specific SEC filing. The management section tracks promises vs delivery across 5 years. The moat section quantifies pricing power through 10 years of same-store sales during inflation. The report doesn't persuade — it *illuminates*.

## Key Architecture Decisions (from CEO Review)

### 1. Portfolio Manager / Analyst Team Model
The user is the portfolio manager. The AI agents are the analyst team. When agents hit data walls, they ASK the user instead of guessing. The user provides context, challenges assumptions, and redirects research. The system produces a collaborative research product, not an autonomous black box.

### 2. GSD-Style Agent Dispatching
Commands (`/generate:pitch-deck LULU`) orchestrate the flow. They read agent definitions from the `agents/` directory and spawn subagents via Claude Code's Agent tool. Each agent gets a fresh context window with its specific prompt + curriculum + data slice. Agents run in parallel where possible.

```
/generate:pitch-deck LULU
  │
  ▼
ORCHESTRATOR (the skill)
  ├── Spawns: data-assembler → DataPacket
  ├── Spawns: primary-source-reader → 10-K insights, transcripts, promises
  ├── PHASE 1 (parallel): 3x business-analyst → Sections 1-3
  ├── CHECKPOINT → user reviews + answers questions
  ├── PHASE 2 (sequential): business/financial/management → Sections 4-8
  ├── CHECKPOINT → user reviews
  ├── PHASE 3: risk-analyst + valuation-specialist → Sections 9-10
  ├── CHECKPOINT → FGR confirmation
  └── synthesis-writer → final polish
```

### 5. Structured Checkpoints (PM/Analyst Model)

After each phase, the orchestrator presents:
- Section findings (key insights per section)
- Data gaps ("Couldn't find COST's maintenance capex breakdown")
- Questions ("Web search returned conflicting market size numbers — which to trust?")
- Confidence levels per section

User responds with: answers, corrections, additional data, or "proceed."

### 6. Web Search + Pluggable Data Architecture

Start with web search. Design the agent prompt interface so any data source (web search, IR scraper, analyst API, user-provided data) can be swapped in per-section. Build custom scrapers only when web search proves insufficient. When agents hit paywalls or inaccessible data, they escalate to the user.

### 7. Management Promise Tracker (in Primary Source Reader)

The Primary Source Reader extracts from earnings call transcripts:
- Forward-looking statements (revenue guidance, growth targets, strategic plans)
- Tags each promise with quarter/year
- In subsequent analyses, compares promises to actual results
- Produces management credibility metrics for the Management section

Architecture: `promises` data structure in the report model per ticker.

### 8. Presentation-Ready PDF Export (Phase 8, First-Class)

ExportView.jsx + PDF generation using existing `scripts/pdf/` toolkit:
- Thes1s branding (logo, teal + slate)
- Formatted tables and charts (from Recharts)
- Numbered citation footnotes
- Executive summary front page
- Section-level verdict badges
- Sensitivity table visualizations

Report schema includes a `charts` field for PDF rendering.
