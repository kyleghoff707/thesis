# CEO Plan: Morningstar-Grade XBRL Engine

## Vision

### 10x Check
Thes1s becomes the open-source Morningstar data layer — a standalone engine that makes paid financial data services unnecessary for fundamental analysis. Any US public company, any year, correct data, zero manual intervention. Self-healing. Industry-aware. Every number traceable to its SEC source.

### Platonic Ideal
Three-layer extraction engine:
- Layer 1: Universal static map (~200 tags, O(1) lookup, covers 96%)
- Layer 2: SEC taxonomy hierarchy resolver (pre-built JSON, cached per-concept)
- Layer 3: Per-company filing adapter (XBRL linkbase parsing, AI disambiguation with confidence gating)

Every value carries parallel provenance metadata. Industry detection customizes extraction for banks/REITs/insurance. Coverage is continuously monitored. Sum-of-parts validation catches silent errors.

## Architecture Decisions

| Decision | Choice | Reasoning |
|----------|--------|-----------|
| Provenance data model | Parallel metadata object | Zero breaking changes to components |
| Taxonomy loading | Pre-built JSON at build time | Zero runtime parse cost; update annually |
| AI safety (Layer 3) | Confidence threshold + sum-of-parts | Belt and suspenders against silent wrong data |
| Implementation approach | Hybrid (incremental + adapters) | Immediate value + long-term architecture |

## Accepted Scope
- Three-layer engine: Static tags → Taxonomy hierarchy resolver → Per-company adapters
- Pre-built taxonomy JSON (build-time processed from SEC US-GAAP XML)
- Parallel provenance metadata on every extracted value
- Confidence indicators in UI (direct / derived / inferred)
- Industry detection + specialized extraction (banks, REITs, insurance)
- Sum-of-parts validation for cross-checking
- Background coverage monitoring with Audit tab alerts
- Live taxonomy coverage dashboard in Audit tab
- AI confidence gating (Layer 3, <80% → "inferred" with warning)
