## Edge Cases
- Company with very low Tier 1 coverage (from audit worst-performers) — should show missing fields in provenance, not wrong data
- Company that changed XBRL structure between filing years — should show different tags per year in provenance
- Non-dividend-paying company — dividends_per_share should be null, not zero, with "not reported" provenance
- Company with derived liabilities (L&E - E) — provenance should show "derived" with formula

## Critical Paths
- Three-layer fallback: Layer 1 miss → Layer 2 resolves from taxonomy JSON → correct value shown
- Three-layer fallback: Layers 1+2 miss → Layer 3 AI classifies unknown tag → correct value with confidence indicator
- Industry detection → overlay application → bank/REIT/insurance-specific fields present in Financials tab
- Sum-of-parts validation: Assets ≠ Liabilities + Equity → mismatch flagged in Audit tab
