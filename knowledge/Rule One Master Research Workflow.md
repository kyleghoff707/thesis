Rule One Master Research Workflow

Purpose

This document governs the complete Rule One research process.

It defines:
	•	Stage progression
	•	Folder structure meaning
	•	Which documents are references vs templates
	•	When to escalate
	•	When to stop

This is the orchestration layer for Claude agents.

⸻

Folder Architecture Meaning

1️⃣ Company Research (Reference Library)

These files are educational + methodological references.

They explain how to think.

They are not company-specific outputs.

Includes:
	•	Advanced_Financial_Statement_Analysis.md
	•	Financial Statements and FGR.md
	•	Guru Reference List.md
	•	Pitch Deck II.md
	•	Pitch Deck III.md
	•	Pitch Deck IV.md
	•	The Pitch Deck.md
	•	The Search Begins.md
	•	Tools for Analysis.md

Claude should use these files to:
	•	Understand methodology
	•	Learn calculation logic
	•	Apply growth frameworks
	•	Apply moat frameworks
	•	Apply valuation models

These are background knowledge files.

⸻

2️⃣ Research Templates (Execution Frameworks)

These files define structure.

They are the forms Claude fills out during analysis.

Includes:
	•	Rule One one-pager
	•	Rule One Pitch Deck Template.md
	•	Rule One Story Form - Resources.md
	•	Rule One Story Form.md
	•	Rule One Master Research Workflow.md

Claude must:
	•	Follow these templates exactly
	•	Not invent new section structures
	•	Fill them sequentially
	•	Escalate only after completion

⸻

3️⃣ Full Story (Deep Conviction)

These files represent:

Completed, high-conviction company analyses.

Includes:
	•	Story Form I.md
	•	Story Form II.md

These represent structured conviction engineering.

Claude should not begin here.

It must earn its way here.

Research Flow (Stage-Gated)

Stage 1 — One Pager

Template Used:
→ Rule One one-pager

Reference Files:
→ Financial Statements and FGR
→ Tools for Analysis
→ Guru Reference List

Objective:
Filter quickly.

Stop if:
	•	Business unclear
	•	Growth inconsistent
	•	Debt excessive
	•	Returns weak

Do not escalate without pass.

⸻

Stage 2 — Pitch Deck

Template Used:
→ Rule One Pitch Deck Template.md

Reference Files:
→ The Pitch Deck
→ Pitch Deck II
→ Pitch Deck III
→ Pitch Deck IV
→ Financial Statements and FGR
→ Tools for Analysis
→ Guru Reference List

Objective:
Build structured business case.

Stop if:
	•	Moat unclear
	•	Management questionable
	•	Debt risky
	•	Growth unsustainable
	•	Valuation unsupported

Escalate only if durable thesis exists.

⸻

Stage 3 — Full Story

Templates Used:
→ Rule One Story Form.md
→ Story Form I
→ Story Form II

Reference Files:
→ Rule One Story Form - Resources
→ Pitch Deck IV (valuation systems)
→ Portfolio & Bankroll Management
→ Cost Basis & Tranching

Objective:
Engineer conviction.

Requirements:
	•	Inversion & rebuttal complete
	•	Backtesting complete
	•	Trading strategy defined
	•	Allocation strategy defined
	•	PACE plan defined

Only after completion may capital be deployed.

⸻

Operating Rules for Claude
	1.	Never skip stages.
	2.	Never assume Guru ownership is a buy signal.
	3.	Always prefer conservative growth.
	4.	Always test inversion.
	5.	Always define exit before entry.
	6.	Always document assumptions.
	7.	Stop when clarity fails.
